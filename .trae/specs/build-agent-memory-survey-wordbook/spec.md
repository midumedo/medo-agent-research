# 生成 Agent Memory 综述阅读单词本 Spec

## Why
读者正在读五篇 agent memory 英文综述，需要一个可边读边查的读词工具：术语、句式、符号、读表方法都锚定在这五篇的真实原句上，而不是百科式词表。

## What Changes
- 新建唯一交付文件 `resources/papers/单词本.md`。
- 结构固定为五块 + 冲突节：
  1. 怎么读这批 Survey（章节骨架、先看哪三处）
  2. 术语（六组：基座概念 / 载体与计算 / 记忆操作 / 记忆类型 / 评测与指标 / 工程实现）
  3. 论文句法与套语（15–25 条，英文模板 + 中文语用说明 + 真实原句）
  4. 符号与记号（仅收五篇中实际出现的符号）
  5. 表格与实验读法
  6. 五篇之间的用法冲突（只登记事实与出处）
- **BREAKING**：不含任何备考内容（熟词僻义、词根词缀、例句分级、记忆技巧）。
- 不改动 `resources/papers/md/`、`md-zh/` 及其它既有文件。

## Impact
- Affected specs: 无（首次创建）
- Affected code: 仅新增 `resources/papers/单词本.md`；临时目录 `.tmp_wordbook/` 在合并校验后删除。

## ADDED Requirements

### Requirement: 五块结构
系统 SHALL 按「怎么读 / 术语 / 句法与套语 / 符号 / 表格读法 / 用法冲突」顺序输出内容。

#### Scenario: 结构完整
- **WHEN** 打开 `单词本.md`
- **THEN** 六个一级章节齐全，术语六组齐全

### Requirement: 每条术语有原句依据
系统 SHALL 为每条术语给出一条英文原句与出处（文件简写 + 行号），且该句能在对应 md 中检索到。

#### Scenario: 校验通过
- **WHEN** 对引号内片段做 Grep
- **THEN** 命中对应论文文件

### Requirement: 符号只收实际出现者
系统 SHALL 只解释五篇正文中出现过的符号，并注明未出现的符号（如 D/O/N 未作为独立形式符号出现）。

#### Scenario: 不臆造符号
- **WHEN** 读者查符号表
- **THEN** 每个符号都有正文出处或明确"未出现"标注

### Requirement: 冲突只登记事实
系统 SHALL 在最后一节列出跨论文用法差异，注明双方出处，不做调和与判断。

#### Scenario: 冲突可追溯
- **WHEN** 读者读冲突节
- **THEN** 每条至少有两个出处，且不含评价性结论

### Requirement: 无备考痕迹
系统 SHALL NOT 出现熟词僻义、词根词缀、备考高频词、例句难度分级、记忆技巧等内容。

#### Scenario: 定位纯净
- **WHEN** 全文检索"词根""熟词""高频""记忆技巧"
- **THEN** 无命中
