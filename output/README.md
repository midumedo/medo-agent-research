# Output：教材设计与后续成品

这里按读者用途组织教材设计、章节与手册。当前两条路线都处于设计阶段，尚无完成的教材正文或运行案例。

| 路线 | 当前安排 | 阅读入口 |
|---|---|---|
| Agent Memory：机制、实现与工程取舍 | 当前优先。八章主干，从真实记忆需要进入简单实现、读取、写入、变化、工作记录、成本与选型；关系和经验按需深入 | [Memory 教材设计](book-memory/design.md) |
| Harness、Context 与 Memory 的整体运行 | 保留为后续路线。原十一章设计提供更广的执行、状态、协作与恢复视角 | [整体运行教材设计](<harness book/book-design.md>) |

Memory 专题围绕“什么过去信息值得保留，怎样使它在未来有用”展开；整体运行路线围绕“一次持续任务怎样正确行动”展开。两者可以共享研究材料，不要求前一本压缩或复刻后一本。

框架筛选理由见 [Memory 工程选择](../analysis/memory-engineering-selection.md)，对象版本与机制片段见 [一手材料](../evidence/domain/memory-frameworks-core-2026-09-21.md)。它们支撑编辑判断，但不被教材顺序限制。主题综合仍在 [Domain](../domain/index.md)，原始资料和具体对象拆解可分别深入。
