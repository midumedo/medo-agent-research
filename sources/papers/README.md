# 论文库

外部论文的**原件**与**机器转换件**。给人看的入口只有这一页；规则（怎么做、字段怎么读）在 AGENTS.md，历史在 CHANGELOG.md，清单在 index.csv。

## 一篇论文由什么组成

共同的文件名词干是 `<id>.<类型>.<名称>`，例：`arxiv-2502.12110v11.Project.A-Mem`。
`id`（`arxiv-2502.12110v11`）是**永久身份**——登记处 + 编号 + 版本，改名称也不会改它；引用时给 `id`。

| 位置 | 是什么 |
|---|---|
| `pdf/<名>.pdf` | 原件，不改 |
| `md/<名>.md` | 机器转换的正文。顶部 front matter 是本项目的**登记块**：关键词、摘要、来源、解析器版本、进度 |
| `assets/<id>-*` | 从 PDF 抽出的图，平铺一层，名字自带归属：`<id>-fig3`／`-table2`／`-chart1`／`-eq1`／`-img1` |

## 找一篇、读一篇

- **找**：打开 `index.csv`——一行一版本，四列 `id, name, keywords, revised`。按 `keywords` 挑主题、按 `revised` 挑新旧；文件名由 `id` + `.` + `name` 拼出来。
- **读**：直接读 `md/<名>.md`，front matter 里有摘要，正文是全文。
- **核**：引用具体数字、表格、公式前，回 `pdf/` 定位原文核对。**机器转换文本不等于原文。**

## 收录不等于核实

- 转换成功 ≠ 已对 PDF 做过视觉核验（`visual_verification` 默认 false）。
- 缺失的字段记 `unknown` 或留空，**不推测**。
- 材料份数以 index.csv 为准，不在文档里写死数字。

## 目录里还有什么

`_scripts/` 是下载与转换工具，**零第三方依赖**（只用标准库），跑法见 AGENTS.md；它属于工具，不属于外部证据。除 `index.csv` 与各篇 md 的登记块外不再另存快照文件——缺的信息现取即可，判据见 AGENTS 的「只留两份，其余现取」。
