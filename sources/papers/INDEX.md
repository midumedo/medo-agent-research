# 论文库索引

`sources/papers/` 的**当前清单**与**只追加日志**。规则、流程与禁止事项见 [AGENTS.md](AGENTS.md)；给人看的说明见 [README.md](README.md)。

- 一个标识 = 一篇论文；同一标识在 `pdf/`、`md/`、`json/` 下同名路由：`pdf/<标识>.pdf` ↔ `md/<标识>.md` ↔ `json/<标识>.json`。
- 清单按标识排序，是**当前视图**：发现事实错误可就地更正，但每次更正必须在下方日志留痕。
- 日志**只追加，不删改**；新论文入库、改名、重新转换、更正都在这里记一行。
- **收录不等于核实。** 机器转换文本不等于已对 PDF 做视觉核验；字段缺失写 `unknown`，不推测。
