ThemodelauditedherebelongstoaclassitsdevelopercallsSystemOnemodels(TypeSafe,2026c).Suchamodel

4.1. Population coding, cost, and the probability landscape
The second stage coded 195,857 of the 5,018,080 narratives in the analyzed corpus with the full 27-question
schema, and 150,000 of them form the random stratum on which every population estimate rests (Table 2). Coding
cost $30.22 in total, which is a realized $0.154 per thousand narratives, so coding the whole corpus at that rate would
cost $774. The median latency was 0.20 seconds, the ninetieth percentile 0.33 seconds, the sustained rate about 44
requests per second, and the mean input 3,673 tokens per narrative, with 0 failed calls. The fitted token model of
Eq. (3) has𝛼= 171,𝛽= 122and𝑏= 0.236tokens per character, with𝑅 2 = 0.987for the question-count model

per call while a median narrative of 378 characters contributes about 89. Each additional question costs a constant
122 tokens regardless of the corpus, so a lean screen is cheaper only in proportion to the questions it omits. Two

4.4. Frontier comparison and value added over the coded fields

5. Discussion
The central answer of this study is that adding calibrated narrative variables to a state’s coded contributing-factor
fields changes the safety diagnosis those fields support. Across the 9 factors that carry a coded counterpart, the
narratives add 10,747 injury and fatal crashes per year to the 28,057 the coded fields record, a median increase of
39%, and 4 of the nine factors change rank. The strongest single case is phone use, which the coded fields make the
smallest of the nine and which the narratives raise by 182%. That result rests on two prior ones that this paper also
establishes. A typed decision model can code narratives at a cost low enough for a state to run the schema over a
population rather than a sample. Its probabilities are usable for ranking but not for counting until they are recalibrated
against a few thousand human judgments. Once that recalibration is in hand, the human review a narrative-derived

6. Conclusion
This study set out to answer two questions that crash-narrative research has left to the reader, namely how much
human checking a narrative-derived variable needs and what changes in a safety diagnosis when such variables are
added to the coded record. Answering them required treating narrative coding as a set of typed, gated decisions with
probabilities attached and auditing the probabilities against an external reference instead of assuming them. It also
required running that decomposition at scale, with a first-stage screen over 499,500 narratives and full coding of

not a prevalence estimate. And risk-coverage analysis imported unchanged from balanced settings certifies rare-event
screeners as needing no review, so the budget has to be defined over the records the model flags.
