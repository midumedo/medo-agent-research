## 当前回答

**减少进入主上下文的信息，与精简已经进入的信息，是可以组合的两类操作。谁更划算，取决于任务效用、完整路径成本以及恢复被省略信息的能力。** 自动压缩的存在不排斥前置过滤；提供两种机制也不证明厂商对它们做过普遍优劣排序。

本文暂将“卸荷”作为一组操作的工作简称：让某些处理或信息驻留发生在主上下文之外。过滤、延迟加载、外部存储、委托给子 agent 并不是相同机制，不能因为共用这个名字就假定它们成本相同、都可恢复或都由确定规则控制。“压缩”在本文指用更短的表示替换一部分工作上下文；原始记录是否另存，需独立说明。

## 三个应当分开比较的问题

### 全路径成本：主上下文变短，不保证任务总成本变低

前置过滤可能减少后续多轮重复输入；压缩可能需要一次额外总结；子 agent 可能需要额外读取、推理、汇报和结果核查；延迟加载可能把成本推迟到确实需要时。比较必须覆盖这些路径，而非只数主 agent 看见多少 token。

**推断**：当被省略材料长、未来驻留轮数多、再取概率低且再取便宜时，保留短指针通常具有成本优势。反之，短任务、频繁重取或昂贵委托可能使收益消失。具体边界取决于缓存与计费，见[上下文经济学分析](context-economics-two-traps.md#residency-cost)。这里尚无实际费用或耗时结果。

### 可恢复性：取决于保留、寻址与恢复动作

工作上下文中的摘要有损，不等于原文已经删除。若原始轨迹另存且可寻址，摘要可以与按需恢复并用。过滤也不自动可恢复：瞬时工具结果若从未保存，后续重跑可能得到不同状态；子 agent 的上下文若不可访问，声称“它还在那里”也无助于恢复。

判断恢复能力需要逐项确认：原文是否保留、身份和版本是否明确、当前状态是否包含可用指针、系统是否知道何时需要恢复、恢复后能否验证材料仍然适用。最后两项失败时，磁盘上有原文也可能表现为遗忘。

**构造性反例，非实测**：压缩聊天轨迹但保存完整原文与定位标识，可能比只保留 ERROR 行且丢弃原始日志更可恢复。因此，“压缩不可逆、卸荷可逆”不能作为两类操作的定义。

### 选择质量：确定执行不等于选对信息

规则过滤可重复、易检查，但会遗漏不符合规则的关键内容。例如错误原因可能写在没有 ERROR 字样的配置输出中。模型摘要能利用语义线索，也可能遗漏低频约束或改变语义。子 agent 的汇报同样可能使用模型选择信息。

压缩焦点或用户规则能够表达任务偏好，这不证明自动推断不可能。更准确的问题是：在用户没有补充偏好时，默认策略会遗漏哪些任务关键状态；补充控制之后，错误是否减少、配置和维护成本增加多少。

## 暂可采用的选择条件

| 条件 | 值得优先尝试 | 需要防住的失败 |
|---|---|---|
| 大量材料与当前目标无关，原文稳定且容易再取 | 精确检索、过滤后保留指针、延迟加载 | 漏检后不知道自己遗漏了什么 |
| 子任务边界明确，返回物可独立检查 | 委托子 agent，约定返回证据和限制 | 汇报压缩掉跨任务约束；总成本上升 |
| 需要延续任务状态，历史过长且无法全部驻留 | 摘要与关键约束保留，配原始轨迹寻址 | 摘要漂移、旧约束丢失、恢复触发失败 |
| 后续步骤频繁依赖原文细节，恢复昂贵 | 保留必要原文，减少无关内容 | 输入过长、注意力干扰及持续输入成本 |

这是机制推断形成的研究起点，不是经过验证的产品操作指南。任务效用相当这一前提一旦不成立，就不能仅凭费用更低宣布方案更好。

## 不再用阶段命名制造冲突

注入阶段可以含准入、拒绝和延迟，召回策略可以选择不召回；流水线并不天然默认放行。因而无需为了容纳“让信息别进来”就断言生命周期模型失效。应该显式画出信息从原文到表示、从外部存储到当前上下文的迁移，以及各迁移的触发与控制权。

“谁决定存、取、丢”已有直接的研究先例，见[本地论文核对：控制策略](../../evidence/domain/reviewed-local-passages.md#control-policy)。本项目要补充的可以是具体工程边界和失败条件，而非宣称这一问题此前无人提出。类似地，不能因某个 harness 没暴露持久库的去重接口，就推断它没有信息治理。

## 下一项能改变判断的验证

选定一个可观察请求与轨迹的运行框架，固定版本、模型、工具环境和任务输入，对比：保留原文；前置过滤并保留可寻址原文；摘要并保留同样原文。让一部分约束只在任务后段起作用，避免只测当前摘要是否流畅。

记录任务完成与关键约束遵守、原文恢复成功率、实际工具调用和输入输出量、缓存读写、压缩请求、费用及耗时。先做小规模成对试验寻找反例，再决定是否扩大；同一设置需考虑模型随机性，不能把单次差异当作普遍规律。

若前置过滤反复遗漏关键状态而摘要保留了它，便直接否定“卸荷严格占优”；若摘要配原文定位能够稳定恢复，便否定“压缩必然不可逆”。若更短主上下文反而导致更多重取和返工，就需要改写只看输入长度的成本判断。本轮只提出这些判据，没有执行实验。
