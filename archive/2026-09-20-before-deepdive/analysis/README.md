## 来源阅读

论文原件与解析正文在 [sources/papers/](../sources/papers/README.md)。我方材料分别从这里进入：

- [早期领域调研](landscape/memory-landscape-2026-09.md)：保留历史原稿；尚未完成逐项事实复核，不能自动当作当前事实底座。

不把导航意见当成论文原话，也不把历史报告当作独立交叉验证。

外部证据可以直接链接原文小节；需要固定摘录时放 `evidence/`。当前解释放 [domain/](../domain/index.md)。研究设计与已运行结果必须分开标明。

## 开始下一次研究

从一个具体选择或异常出发，优先选择能区分竞争解释的材料或实验；不要求写“完整产品说明书”，也不要求每次都推翻主线。

写清已看见什么、尚不能推出什么，以及哪一项新观察值得继续。关键结论变化后，同步引用它的现行认知与入口。维护方式见 [project-maintenance](../.workbuddy/skills/project-maintenance/SKILL.md)。
