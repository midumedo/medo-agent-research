# notes/ · 项目决定

这里回答：**我们决定怎样组织、研究或推进本项目，为什么，改变决定的条件是什么？**

它记录项目选择，不承担领域事实、临时观察或所有“笔记”的收纳功能。决定可以引用研究依据，但决定采用一个解释，不会让解释因此被证实。

| 内容 | 合适位置 |
|---|---|
| 某项目的状态更新路径是什么 | `deepdive/` |
| 为什么旧值会在下一轮复活 | `analysis/`，或对象深拆中的局部问题 |
| 我们当前怎样理解更新传播 | `domain/` |
| 本阶段先拆对象，暂缓编教材 | `notes/` |
| 对话中怎么想到这个方向、否掉了什么 | `dialogue/` |

尚未完成的研究也留在对应研究中，标明未知。这里不成为“想法还不够成熟所以先放 notes”的候车室。
