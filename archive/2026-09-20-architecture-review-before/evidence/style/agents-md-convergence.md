# 依据：为什么统一写作 AGENTS.md

支撑 `STYLE.md` 第一条术语约定。

---

## 事实

- 项目级常驻指令文件正在跨厂商收敛到 AGENTS.md，由基金会托管。
- Claude Code 已支持读取 AGENTS.md。
- Codex CLI、Gemini CLI 各有自己的主文件名（AGENTS.md / GEMINI.md）。

## 为什么这条约定值一条术语规则

多工具团队里，各家 CLI **默认互不读取对方的指令文件**——这是上下文漂移的直接根因：同一个仓库，
用 Codex 的人和用 Claude Code 的人看到的约束不一样，而且两边都不知道对方看到的不是同一份。

统一到 AGENTS.md 作为唯一真源，再用导入语法或软链接对齐各家，是收敛成本最低的方式。

## 还没验证的部分 `[待验证]`

**共存期的行为没有实测过。** CLAUDE.md 与 AGENTS.md 同时存在时：

- 优先级谁高？
- 会不会**静默**只生效其中一个（没有任何报错）？
- 两者内容冲突时怎么办？

这三个问题没有验证。在验证之前，统一写作 AGENTS.md 只是「降低漂移概率」的措施，
不是「消除漂移」的措施——**别把它当成已解决的问题写进教材。**
