列义：

- **英文原形**：摘记中登记的英文词或词组。
- **是否保留英文**：`保留` 指译本保留英文原形；`名词保留 / 动词中文` 指名动分工；`中文` 指该词在译文中主要用中文；`存疑` 指摘记自身未定或各篇处理不一致。
- **出处**：该词在哪些篇的术语表、句例或存疑节中出现，用上表简写。
- **差异 / 备注**：各篇处理差异、词义边界或摘记原话的压缩；未写「存疑」的差异仍可在第八节查看冲突。

## 三、记忆类型

| :--- | :--- | :--- | :--- | :--- |

| short-term memory | 保留 | 瞬时或短期信息的保持 | MemMech、Rethink、AgeMem、AgentMem | 与 working memory 有时互换，各家未统一；AgentMem 说 short-term memory 对经验进行门控。 |

| memory form / memory structure | 存疑 | 记忆的存在形式 | AgeMem | Table 1 表头作 Memory Structure，正文分类应为 Memory Form；译本保留源文字面，未静默更正。 |

## 八、跨篇冲突

只登记摘记与译文中可观察到的事实，不判断谁对，也不做调和。共 10 项。

### 1. KV cache 的归类

- **Rethink**：称其为 **external parametric memory**，同时又把 KV cache 视为 **short-term memory**。出处：Rethink 摘记与 §2.4.2、§2.2；另见 `单词本 §六.1`。
- **AgeMem**：把它列进 **latent memory**，与 activations、hidden states、latent embeddings 并列。出处：AgeMem §3.3。
- **AgentMem**：把它列进 **internal memory**，并称其为 transient、inference-time memory。出处：AgentMem §3.1.2。
- **MemMech / AutoMem**：源文未出现 KV cache；MemMech 摘记只记「规则要求保留」。
- 结论：同一对象至少被归为 external parametric、short-term、latent、internal 四种格子，未统一。

### 2. agent memory 的边界

- **AgeMem**：把 LLM memory 划出 agent memory，称其「should be considered outside the scope of agent memory」，并说更应归类为 LLM memory 而非 agent memory。出处：AgeMem §2.3.1。
- **AgentMem**：把 parametric memory 与 working states（含 KV cache）都纳入 **internal memory**。出处：AgentMem §3.1.2。
- **Rethink**：把 KV cache 收进 short-term memory，因而也在 agent memory 的边界内。出处：Rethink §2.2。
- **AutoMem**：未单列边界，但把 retrieval-augmented memory stores 收进五类核心机制。
- 结论：AgeMem 划出边界，AgentMem 与 Rethink 又把边界内的对象收进来。

### 3. parametric 的范围

- **MemMech**：只把 fine-tuning 与 knowledge editing 视为 parametric 的实现。出处：MemMech §5.2.2。
- **AgeMem**：把 parametric 分成 **internal**（原权重）与 **external**（adapter、LoRA、proxy model）。出处：AgeMem §3.2。
- **Rethink**：把参数内知识整体视为 parametric，并把 KV cache 称为 **external parametric**。出处：Rethink §2.1、§2.4.2。
- 注意：AgeMem 的 external parametric 指 adapter；Rethink 的 external parametric 指 KV cache。同一个短语指两个不同对象。

### 4. episodic / experiential 是否顶层类型

- **Rethink**：把 episodic、semantic、procedural 并列为 long-term memory 的子类。出处：Rethink §2.2。
- **AgentMem**：也把 episodic、semantic、procedural 并列为 cognitive memory 的类型。出处：AgentMem §3.2.3–§3.2.5。
- **AgeMem**：顶层功能分类是 **factual / experiential / working**；episodic 不作顶层类，而落在 factual 的 past events 与 experiential 的轨迹描述里。出处：AgeMem §4.1、§4.2、§4.2.1。
- **AutoMem**：用 working、episodic、semantic、procedural 作为 **temporal scope** 的四类，并说多数系统只实现其中两层。出处：AutoMem §3.1。
- 结论：顶层切法至少有认知类型、功能类型、时间范围三种。

### 5. consolidation 的阶段归属

- **MemMech**：把 consolidation 与 reflection、forgetting 并列为 **memory management** 的三类操作。出处：MemMech §5.3.2。
- **Rethink**：把 consolidation 放在 **Memory Encoding** 之下。出处：Rethink §2.4.1。
- **AgeMem**：把 consolidation 放在 **Memory Evolution** 之下。出处：AgeMem §5.2。
- **AgentMem**：把 consolidation 作为 memory operation 之一，动词作「整合」。出处：AgentMem §4。
- **AutoMem**：把 episode 到 semantic 的 consolidation 描述为跨 temporal scope 的过渡，并说它 rarely automatic。出处：AutoMem §3.1。
- 结论：同一个词分别属于 management、encoding、evolution、通用 operation 与跨层过渡。

### 6. RAG 的定位

- **AgeMem**：RAG 面向静态外部知识、单次任务调用；agent memory 则是多轮、多任务演化，因而把 RAG 作为外部对照。出处：AgeMem §2.3.2。
- **AutoMem**：把 retrieval-augmented memory stores 直接列为五类核心机制之一，并把 RAG 作为该类起点。出处：AutoMem §4.2。
- **Rethink**：把 RAG 与极长上下文并列，作为当前 agent 的主要依赖。出处：Rethink §2.5。
- 结论：AgeMem 把 RAG 排除在 agent memory 之外；AutoMem 把它收进机制家族；Rethink 把它当作现状描述。

### 7. long prompt / long context 是否算 memory

- **MemMech**：把 long prompts 通常视为 memory contents。出处：MemMech §6.2.3。
- **AgeMem**：把 context engineering 与 agent memory 分开：前者管理 context window 资源，后者管理跨时间认知状态。出处：AgeMem §2.3.3。
- **AutoMem**：明确说 Long context is not memory。出处：AutoMem §5.5。
- **Rethink**：把 long-context 与 long-term memory 并列为不同主题，未把长上下文直接等同于记忆。出处：Rethink 摘记与 §2.2、§2.5。
- 结论：MemMech 直接当记忆；AutoMem 明确否认；AgeMem 用边界划分把两者分开；Rethink 作平行主题。

### 8. integration 与 consolidation 的译法重叠

- **Rethink**：名词写 `integration`，动词写「整合」；名词写 `consolidation`，动词也写「整合」。同句可能出现「integration 可能跨越……整合进……」的双重形态。出处：Rethink 摘记 §3 与译本 L184、L173。
- **AgeMem**：`consolidation` 保留英文，备选「巩固」，并明确不与「整合」混用。出处：AgeMem 摘记 §1。
- **AgentMem**：`consolidation` 名词保留，动词仍作「整合」。出处：AgentMem 摘记 §1。
- **MemMech**：`consolidation` 保留，备选「合并」。出处：MemMech 摘记 §1。
- 结论：同一个中文「整合」对应 integration 与 consolidation 两个英文原形，读者需靠英文原形区分。

### 9. retrieval 的名词 / 动词处理

- **MemMech**：名词 retrieval、动词 retrieve，两者都保留英文。出处：MemMech 摘记 §1。
- **Rethink**：名词一律 retrieval，动词一律中文「检索」。出处：Rethink 摘记 §1、§3。
- **AutoMem**：名词 retrieval，动词 retrieve。出处：AutoMem 摘记 §1。
- **AgeMem、AgentMem**：retrieval 保留英文，动词位置未单列规则，随句处理。
- 结论：名词处理一致，动词处理不一致；中文「检索」在 Rethink 中是动词专用，在其他篇也作普通名词使用。

### 10. experience / experiential 的词根处理

- **AgeMem**：保留 experience，并特意不把 era of experience 译为「经验时代」，以免与 experiential memory 的「经验」混为一个概念。出处：AgeMem 摘记 §2、§3。
- **AgentMem**：正文把 experiences 译为「经验」，同时保留 short-term memory 等英文术语，形成「short-term memory 对哪些经验……」的半混合句。出处：AgentMem 摘记 §2。
- **Rethink**：episodic 保留英文，但搭配的 experience 在句例中作「经验」。出处：Rethink 摘记 §2 句例 11。
- **AutoMem**：保留 experiential memory 所属的类型词，未单列 experience 的译法。
- 结论：experiential 的词根在 AgeMem 保留英文，在 AgentMem、Rethink 的正文落为中文「经验」，未统一。
