# 译法说明

本文件记录五篇 agent memory 综述中译本在术语映射之外的译法问题：与 `术语总表.md` 不一致或本篇特有的定译、尚未解决的存疑，以及源文自身的缺陷。读译文时遇到「为什么这样译」「这里是否译错」「源文是不是有问题」，先查这里。

行号默认指对应 `*.zh.md` 的当前正文行号；标「源文 Lxxx」的指 `../md/` 下机器转换的英文源。正文重跑或行数变动后行号会漂移，引用前按关键词重新定位。

与 `术语总表.md` 的分工：总表管英文原形到中文处理的映射、跨篇冲突与总存疑清单；本文件管总表未覆盖或与总表不一致的定译、逐篇存疑的行号校准、以及源文缺陷，不另立术语标准。逐篇 `*.zh.notes.md` 已停止维护，本文件是译法说明的唯一入口。

## arxiv-2404.13501 Memory Mechanism

### 与总表偏离的定译

- `LLM-based` 拆为「基于 LLM 的」，保留 LLM 与 agent 原形，避免再造「大模型智能体」；开篇即用这一拆法，后续同形。
- `project` 取「投影」而非「投射」，保留函数映射的技术含义（L168）。
- 评价性、修辞性词取中性学术义：`boasts`→「具有」、`key`→「关键」、`intuition`→「直觉」，不按字面译「吹嘘」「钥匙」「思路」（L418、L514、L526）。
- `considerably`→「在很大程度上」而非「极大」；`expected information` 不作「期望信息」，避免统计歧义（L287）。
- `harness`：本篇正文未出现（源文仅参考文献标题含 Harnessing），术语表仅按规则记「保留（本文未出现）」；总表未收该出处，正文无对应替换。

### 存疑

- L81：开篇 Elie Wiesel 引语的 memory 译「记忆」，是全文唯一中文「记忆」处；修辞义与术语义分开处理。
- L309：`knowledge editing` 译「知识编辑」，未保留英文；不在强制保留清单，中文文献通用。
- L370、L424：`coherence`/`consistency`/`engagement` 分别译「连贯性」「一致性」「参与度」，未保留英文；三者需在中文语感上区分。
- L168：`observation` 译「观测」，指环境返回给 agent 的反馈，不保留英文。
- L456：`memory function` 的 function 作叙述词译「功能」，以断开与 memory module 的重复。
- L281：`cache` 作动词时补「做」使句子成立；严格对应原文分词结构时略松。
- L474：`recall` 作动词保留英文，避免中文「回忆」引入心理学色彩。
- L460：`episode memory` 按源文保留原词，未改成 `episodic memory`；同段 memory、context、prompt、SFT 等并置，中英混排密度高，可读性低于其余段落。
- L514：`digital life card` 直译「数字生命卡」，需借同句「可插拔的 parametric memory」才能理解。
- L404：`reference accuracy` 译「参考准确率」，取「参考」而非「引用」，因比对对象是 memory 与 ground truth。

### 源文缺陷

- 源文 L449：`spacial tasks` 疑为 `spatial` 拼写；译本按原义译「空间任务」，未擅改原文拼写（译本 L446）。
- 译本 L460（源文 L463）：源文用 `episode memory`，其余四篇用 `episodic memory`；属跨篇源文不一致，译本未对齐。
- 未见表格截断、图注或页眉混入、参考文献异常。

## arxiv-2505.00675 Rethinking Memory

### 与总表偏离的定译

- `temporal` 译「时间维度」，与 context、模型内部、跨来源三维度统一命名（L47）。
- `publication-age` 译「发表年份」而非「出版年龄」；`mitigating` 保留「缓解」的程度，不写成「消除」（L61）。
- `inference-time` 译「推理时」，不译「推断期」；`enduring` 与 `persistent` 统一「持久」，不引入「耐久」（L82、L167）。
- `mismatch` 译「失配」，与后文 retrieval—generation 的「差距」错开（L196）。
- `overview` 译「概述」，避免与 survey 的「综述」重复（L67）。

### 存疑

- L167、L184：`integration` 与 `consolidation` 的名词都在正文保留，动词却都落为「整合」（L173、L194、L433）；中文无法只凭词面区分两类操作。
- L140：名词一律 `retrieval`，动词一律「检索」（L96 等）；「检索到的 memory」中英混排偏硬，但避免「检索 retrieval」叠词。
- L271：`compression`/`embedding`/`forgetting` 名词保留、动词用「压缩」「嵌入」「遗忘」；严格全保留英文会产生「compression parametric memory」这类不合语法的搭配。
- L90、L269：`lost in the middle` 保留中文「中间迷失」并括注原词；严格按规则应只留英文，属为可读性牺牲形态一致。
- L377：`integration` 形容词化为「更整合的范式」，未改成英文，属顺口牺牲准确性。
- L353、L383、L433：`adapt`/`evolve` 的普通动词义未改英文，以免与类别名 `adapting`/`evolving` 混淆。
- L233：`personalization` 不在保留清单，全文用中文「个性化」；与 `persona`（人物形象）分开。
- L167：原文为 `reasoning experience consolidation`，为可读性补出「经验」二字，结构未变。
- L194：`self-evolution alignment` 作「自演进对齐」，`salient memory distillation` 保留英文；「显著」曾误作中文形容词，已回改。

### 源文缺陷

- 无。未见表格截断、图注或页眉混入、OCR 残渣或参考文献异常。

## arxiv-2512.13564 Age of Agent Memory

### 与总表偏离的定译

- `harness`：本篇正文与源文正文均无该词（源文仅在参考文献标题含 Harnessing），总表所记「评测框架」在正文中无对应；该条不迁移，按实际文本处理。
- `encapsulates` 译「概括」而非「封装」，因为此处说的是概念范围而非实现细节（L674）。
- `biological counterparts` 译「生物对应物」而非「生物体」，比较对象是机制而非物种（L676）。
- `suppressing` 译「抑制」而非「消除」，原文指降低出现概率，不是杜绝（L661）。
- `landscape` 译「层面」而非「图景」，本段讨论概念范围；`acquisition` 译「习得」而非「获取」，贴近认知科学用法（L277、L676）。

### 存疑

- L215、L495：中文「潜在」同时承担 potential 与 latent；L215 作「潜在的未来用途」保留中文，L495 的 latent representation 保留英文，只有明确指向表示空间时才改回 latent。
- L1113、L1169：中文「注意力」同时指 attention 机制与研究关注；L1113「注意力转向」、L1169「注意力自然扩展」指研究关注，机制处仍保留 attention。

### 源文缺陷

- 源文 L117、L119：一句被分页截断（`a capability fundamentally` / `grounded in agent memory.`）；译本保留断行，译本 L119 以「从根本上」收尾、L121 接「植根于 agent memory」，这也是全篇比源文少 19 行的原因之一，非删节。
- 译本 L500：表 3 的 FOT 单元格原表文本为 `memory attention KV`，语义不明，疑为机器转换残留；译本照录，未猜测。
- 译本 L655、L661、L667：源文以行内标签 `Knowledge Persistence`、`Shared Access`、`Summary` 起段，未立小节标题；译文改为粗体标签，结构与正文未严格分层。

## arxiv-2602.06052 Agent Memory

### 与总表偏离的定译

- `gate` 译「门控」而非「控制」，保留筛选机制的技术含义（L7）。
- `augmented with` 译「辅以」，不用「增强」，以免与 memory augmentation 撞词（L95）。
- `independently of` 拆为「独立于……运行」，避免「独立运行于」的歧义（L123）。
- `online` 译「在线」而非「实时」，对齐认知心理学的 online processing；`dominates` 译「占优」而非「主导」，保留比较级含义；`substrate` 以单数承接类指（L105、L163）。

### 存疑

- L350、L303：整合、压缩、嵌入、检索、遗忘、修剪作谓语时仍用中文，未替换为英文名词；英文名词无法直接带中文宾语，硬换会产生「consolidation 为」「retrieval 出」一类病句。
- L303、L305：小节标题用 `Summarization`，正文多作「总结」，词形未统一；为保动词流畅牺牲词形一致。
- L303 等全部小节标题：采「英文术语 + 中文虚词」的混合式，如「4.1.4 Compression 与 Summarization」；全英文标题会与译本定位冲突。
- L145、L147：源文为 `weight-based` / `state-based memory`，译文作 `weight memory` / `state memory` 的混合形。
- L105：源文 `memory traces or memory engrams`，译本合并后各保留一次，弱化「痕迹/印迹」的原措辞。
- L163：`substrate` 不标单复数，按英文 mass noun 习惯处理，中文语境下无法区分。
- L228：`episode` 义项统一为 `episode`，泛称仍用中文「场景」，边界依赖上下文判断。
- L243：`subject-level distinction` 直译「subject 级区分」，略生硬，未找到更自然的等价表达。
- L157、L507：表 1、表 5 的列名仍为中文（「维度」「名称」「环境」「评估」等），未按术语规则英文化。
- L216：`structured` / `hierarchical memory` 的修饰语仍为「结构化/层次化」，仅 memory 保留英文，形成半混合形式。
- L501：`benchmark` 段落仍是长定语，读起来偏绕；源文原残字「确」已修正，但句式未重构。

### 源文缺陷

- 源文 L76、L103、L224（及全篇多处）：英文层系统性缺字，`diferent`→`different`、`bufers`→`buffers`、`eficient`→`efficient`、`efects`→`effects`，疑为 PDF 字形丢失；译本在 L105、L216、L228 等处已静默修正，语义未受影响。
- 未见表格截断、页码或页眉混入、参考文献异常。
