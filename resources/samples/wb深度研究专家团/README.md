
# 7个角色
1. **研究主编（顾全之 · 主理人/团长）**

2. **研究编辑（季要纲）**

3. **课题研究员（谭溯源）**

4. **草稿审稿人（明鉴秋）**

5. **内容修订员（任润泽）**
   
6. **报告撰写人（程文成）**

7. **报告发布员（傅梓铭）**

# 大概流程（推断）
0. 研究主编 负责 与人沟通 和 协调专家发布命令。任何操作都是由其它专家完成
1. 课题研究员 初步调研
2. 研究编辑起草大纲
3. 分章并行研究，大致按照 课题研究员，草稿审核人，内容修订员，依次完成。（但是存在交流，并不是纯单向）
4. 报告撰写
5. 报告发布
   
# sample格式
下面的文奸夹列了一些举例吧，不一定完整。
命名前几位就是大概的顺序。一般是3位xyz，第一位x表示顺序，第二位y表示章节（0表示并不是分章进行，有区分章节的一般能并行执行），第三位z表示版本。
比如
/jev/
1. 100 初步调研
2. 200 大纲起草
3. 分章进行，并行启动，也就是说 x=3的 并行跑，并且，xy=31的跑完，不等其它的，进行xy=41，完了继续xy=51（当然，中间发现了问题，会倒回去查）。 而且有研究主编 进行整体的协调与通知
