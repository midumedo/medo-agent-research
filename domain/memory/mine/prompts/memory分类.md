# 背景
Agent memory 的核心是一个计算问题：一个以 LLM 为中心的 agent，行为由前向计算决定，过去要影响未来，必须经由某种持续存在、可被读取的状态——这种状态在计算上可以放在哪里？位置屈指可数，构成记忆的三个载体：

- **token**：状态存放在符号空间——以离散符号序列存在于模型之外，读取时作为输入进入计算；
- **parametric**：状态存放在参数空间——记忆即权重的一部分，读取内在于前向计算本身；
- **latent**：状态存放在表征空间——以连续向量形式存在于模型之外，读取时注入计算的中间层。

三个是位置而非互斥的类别，一个系统的记忆可以同时分布在多处。

我正在搭建 agent memory 的对比式研究框架——系统分类与深入理解，不提出新方法。载体问题已在框架中处理，本篇不重开；本篇进入 token 位置内部，问下一个问题：同在 token 位置上的系统与系统之间，真正在哪些维度上不同？

这个问题在 token 位置上特别有内容，因为它有一组生成全部设计自由度的约束：上下文窗口有限，外部符号存储无界，读取只能经由输入，载体离散、存放于模型之外。存什么、以什么形态存、如何组织、如何被选中进入上下文——每一个都是独立可变的设计自由度；token memory 的设计空间，本质上是对这组约束的结构性回应。

本篇的产出不是又一篇文章，而是一组坐标轴：后续所有 token memory 研究——包括记忆生命周期一章——都在这组坐标上定位与比较。轴漏了，后面每一章都有系统性盲区；轴混了，后面每一次比较都错位。

这个领域还有一个特殊处境：常用分类词汇大量是继承来的——人类记忆心理学、信息检索、数据库实践各贡献了一批。继承不是错误，但这些分类成形时所受的约束（人脑的巩固与遗忘机制、检索系统的查询假设）与 LLM agent 的约束不同。哪些区分真的迁移了过来，哪些只是词汇惯性，需要逐个论证——这是本篇任务的一半。

# 任务
写一篇自足的深度参考文章，两件交织的工作：

**推导维度。** 从 token memory 的结构约束出发（有限上下文、无界外部存储、读取经由输入、离散符号、模型外存放），推导系统设计的自由度。推导之前先显式回答一个问题：什么使一个轴成立——可独立变化、且变化携带后续研究关心的差异——这个判据本身需要论证，此处只指出方向。

**审计习用分类。** 盘点领域内常见的分类——无论来自心理学词汇、工程实践还是综述传统——逐一裁定：它实际追踪哪条（或哪几条）真实轴；哪里发生混叠；它成形时受的领域约束在这里是否仍成立。裁定必须忠实于实际用法：同一术语在不同文献里用法不同，这个分歧本身就是发现；审计每个分类的最强版本，不审计稻草人。

产出是一个明确的维度集，作为后续研究的坐标。每个习用分类得到裁决：对应主轴 / 修正后采用 / 降级为描述性词汇并附批评。

# 要求
产出会向下传播进整个研究框架，四条要求都由这个事实推出，每条同时点名它要纠正的默认写法：

**详尽**：维度集是后续一切 token 研究的坐标系。默认行为是把覆盖度写到“一篇合理文章”为止，这里的标准是穷尽：漏一条轴，就是后面每一章的系统性盲区；习用分类的盘点要求完备而非抽样。看似显然或无趣的维度同样显式处理：无名之轴比乏味之轴危害更大。

**准确**：机制按机制写——状态在哪里、经过什么计算、产生什么效果，不用类比或“本质上相当于”替代。被审计的分类按实际用法呈现。术语首次出现即定义。

**无偏**：裁定的风险是双向的。一端是继承崇拜——默认把“被广泛使用”当作“分类有效”的证据，让习用词汇无声成为主轴；另一端是表演式拆解——以“来自心理学”为理由直接降级，用出身代替论证。裁定只能依据判据：对准真实轴的继承分类存活，降级必须指出具体的失败模式。出身是线索，不是判决。

**第一性原理**：轴必须从结构推导出来，不是从文献类别汇编而来。文献的角色是双重的，必须分清：文献中的习用分类是审计对象——是任务的 subject，不是框架的来源；文献中的机制事实是证据。一个苛刻的自检：如果推导出的维度集与习用分类完美重合，先怀疑推导没有真实发生，再考虑“继承分类恰好都对”。
