# 正文
## 1. 引言：无状态函数与记忆问题
### 1.1 物理起点
以大语言模型为计算核的 agent，其核心是函数 f_θ(x)：给定权重 θ 与输入序列 x，产生输出分布。函数本身无状态：两次调用之间，除非有信息被显式地从一次调用搬运到下一次调用，否则两次调用在因果上独立。多轮对话中上一轮影响本轮输出，不是因为模型“记得”，而是因为系统把上一轮文本重新拼入了本轮输入。**[V]**
这是 agent memory 问题的物理起点：LLM 无状态，而 agent 需要跨调用地利用信息。落差必须由两个操作弥合：信息被持久化于某处；信息在后续计算中重新进入。前一问引出“载体在哪里”，后一问引出“以什么身份参与计算”。
### 1.2 本文的问法与既有分类的关系
既有综述（Hu et al., 2025 [C]；Tang et al., 2026 [C]）将上述两问合并为“信息存于何处”，得到广为使用的三形态分类：token（外部离散符号）、parametric（参数值）、latent（表征空间内的连续张量）。该分类的物理依据是：影响 f_θ 输出的信息只能经三个位置进入前向计算——输入 token 序列（经嵌入查表）、参数值（作为计算系数）、中间激活（作为外部注入的连续向量）。**[AC]**
本文不改这一依据，而在其上提一个先行的问题：**持久状态以什么身份参与计算——被某个固定过程读取（数据），还是构成计算过程本身（映射）？**这个区分是存储程序计算机的古老洞察（程序与数据是同样的比特，区分在角色不在基底）。本文主张：以角色为第一轴、以管线位置为第二轴，能够统一处理三形态框架下登记为“无共识”的多类边界对象。该主张本身属工具性断言，其成立判据与替代读法见 §3.3 与 §11.3。
### 1.3 认识论分层
本文的全部陈述分三层，各层认识论地位不同，全文坚持分层标注：
- **第一层 [A]（分析的）**：状态要么作为输入被固定过程消费，要么作为过程的组成（系数、规则、程序）。此二分近乎重言式。风险不在错误而在无用；无用判据：若不能比既有分类更好地裁决边界案例，则弃。
- **第二层 [AC]（架构条件的）**：将 agent 管线分解为 O∘D∘f（编排器、解码器、模型），枚举状态可作用的六个面。完备性以该分解为条件，§3.6 给出反例与证伪条件。
- **第三层（经验的）**：各通道基底物化的实例及其成本、容量、失败定律。全部经验内容与数量级在此层，附证据标签。
### 1.4 结构路线
§2 给出功能需求与两个边界判据；§3 完成通道枚举；§4–§5 详述六通道；§6 处理跨通道对象（桥）；§7 经济学与容量；§8 对照表；§9 认知科学参照；§10 失败与攻击面总表；§11 能力、限度、与三形态框架的公平比较、证伪条件；§12 开放问题；§13 结语。

## 2. 功能需求与边界判据
### 2.1 六项功能组件
从系统视角，实用的 agent memory 必须同时满足：**持久化**（信息在请求间存活）、**重注入**（信息进入后续计算）、**选择**（决定注入什么）、**更新/淘汰**（处理过时、冲突、冗余）、**作用域管理**（谁可读写）、**治理/安全**（可审计、可删除、可回滚）。**[A]（功能列举）**
六项不同等原始。持久化与重注入是**物理必要条件**；其余四项是**设计必要条件**——实用系统必须处理，但属操作层问题而非载体层问题。文献中“缓存与记忆之别”“RAG 与记忆之别”的多数表观分歧，是操作层差异被误置为载体层差异的产物（读取是否被当前查询参数化、内容是否动态演化、检索对象是自身经验还是外部语料——这些都不改变载体类别）。**[A]**
### 2.2 重注入的管线级重定义
本文将“重注入”的物理必要条件放宽到管线级：重注入可进入 f 的输入，也可进入 D（解码约束）或 O（编排器读取）。此为分析单位选择，§3.1 显式声明。
### 2.3 判据一：缓存与记忆——权威副本判据
**记忆 = 权威副本**：删除后信息永久损失，不存在可再生源。**缓存 = 可再生投影**：外部存在权威源，丢弃无损（至多损失重算时间）。此判据在信息守恒层面，低于“读取是否参数化”的操作层判据。裁决实例：前缀缓存的 KV 副本可再生自文本 → 缓存；自学习 KV 工件（Cartridges 类）若无存续的源文本 → 记忆，KV 即权威本体。**[A]**
操作层判据（读取参数化、内容演化）保留为次级描述维度，见 §6.4。
### 2.4 判据二：记忆与配置/资产
按纯结构判据（持久 + 重注入 + 影响行为），“记忆”将无界扩张：系统提示、few-shot 示例库、技能描述文件尽数入册，与“配置”“资产”失去界线。本文采用宣布式划界：**内容源于交互历史且影响后续行为的状态为记忆；预先 authored、不随经验修订的静态内容为配置**。经经验修订的系统提示是记忆；出厂系统提示是配置。**[A]（宣布，非发现）**

## 3. 通道枚举：第一性推导
### 3.1 分析单位
本文显式采用两级单位：**LLM 请求**（分析 f 与 D 的信息入口）与 **agent 回合**（分析 O 的信息入口）。环境/世界状态经工具作用与观测回流影响 agent，属 agent 边界之外，显式排除——排除是宣布。单位选择不是序言性细节：以 LLM 请求为唯一单位时，编排器读取的状态从视野中消失（这正是三形态框架排除控制面的机制）；以 agent 回合为单位时它们重新在场。
### 3.2 管线分解
一个回合的计算管线建模为：
> y_t = O_t( D_t( f_θ(x_t) ) )，其中 x_t 由 O_t 组装
O 为编排器（组装输入、路由、工具调度、维护自身状态），D 为解码器（logits → 样本），f_θ 为模型前向。**[AC]**（该分解对当前 agent 工程成立；若 O 本身由另一 LLM 实现，则该子层有自己的 O′∘D′∘f′，框架按层递归适用，见 §11.3 之限制。）
### 3.3 数据/映射二分，及其自检
持久状态以两种身份进入计算：作为 f（或 D、O）的**输入数据**——被一个固定过程读取、其内容由过程消费；或作为过程的**映射**组成——系数、规则、程序，构成过程本身。**[A]**
自检三条，防此轴重蹈它所取代的轴的覆辙：
1. **使用相对性**：角色相对于使用时刻成立。程序文件在被加载前是数据（token），执行中是映射。这正是 §6 桥现象的定义来源，不是轴的失败，而是轴预测的现象。
2. **D 面的弱判定**：logit bias 向量既可读作“加在 logits 上的系数”（映射），也可读作“被 D 消费的偏好数据”。本文按“是否修改过程本身的变换规则”归映射，但承认此处判据弱于 f 面的判据（f 面有清晰的两分：被注意力读取 vs 参与矩阵乘法）。
3. **工具性价值判据**：[A] 层的轴不可证伪，其存废判据为 §6.4 边界案例裁决质量与 §7 容量经济学的推导力。若两处均无增益，此轴应弃。
### 3.4 六通道枚举
| 面 | 状态角色 | 通道 | 读取路径 |
|---|---|---|---|
| f 输入面 | 数据（离散符号） | **token** | tokenize → 嵌入查表 → 逐层前向 |
| f 输入面 | 数据（θ 外、表征空间、跨边界搬运的连续张量） | **latent** | KV 拼接 / 嵌入位注入 / 层间注入 |
| f 系数面 | 映射（参数值） | **parametric** | 无独立读取动作，内在于前向 |
| D 规则面 | 映射（解码约束组件） | **解码态** | 约束解码 / logit bias / schema 强制 |
| O 状态面 | 数据（编排器读取） | **控制态** | 编排器逻辑读取 |
| O 程序面 | 映射（编排器代码、习得工作流） | **程序** | 装载后执行 |
边缘通道登记以求枚举诚实：**受控采样种子**是持久的、可影响输出分布的选择通道，信息论上成立；以其极低带宽排除出记忆讨论，排除为宣布。**[AC]**
三形态框架与六通道的精确关系：token、latent 为数据通道下的两个基底子类；parametric 为映射通道之一；解码态、控制态、程序在三形态枚举的视野外；控制面被三形态以定义选择排除，在本文以分析单位扩展纳入。因此“三形态”轴混合了两个层面（数据基底 vs 映射通道），这是 §11.3 比较的核心议题之一。
### 3.5 架构条件性与显式反例
枚举以 Transformer 前向为条件。反例：循环/状态空间架构（Mamba [V]、RWKV [V]）的跨请求持久隐藏状态——θ 之外的连续张量，却既非“模型外”（它是推理态本身）也不经“注入接口”（它是计算的自然起点）。
修复后的 latent 定义：**θ 之外、处于表征空间、跨计算边界显式搬运的连续状态**。此定义同时容纳两类：模型外存储、注入复用（KV 拼接）与模型内持续、直接续算（循环态）。附带统一效果：在 transformer-as-RNN 视角下，KV cache 即 Transformer 的循环态，故“请求内 KV cache 是否记忆”不再需要特设裁定——它是本次计算的执行结构；跨请求持久化才越过 §2.3/§2.4 的记忆边界。**[AC]**
### 3.6 枚举完备性的条件与证伪
完备性声明：给定 O∘D∘f 分解与当前架构，凡“持久 + 重注入 + 携带信息内容”的状态可归入六通道之一。证伪条件：出现不可归约于六通道的新干预面。**[P]** 需注意分解本身的递归性：若 O 由 LLM 实现，控制态在该子层是 token——枚举按层成立而非全局唯一成立，此为框架的已知结构限制，登记于 §11.3。

## 4. 数据通道
### 4.1 Token：离散符号
#### 4.1.1 机制
**存储**：离散符号序列，位于模型外任意介质（文件、关系库、图库、向量库文本字段）。与模型部署完全解耦；任何能产出文本的系统可写入（agent 摘要、环境日志、用户输入）。
**读取完整链**：选择（从库中选子集）→ 序列化（条目转字符串）→ 组装（与指令、查询拼接）→ tokenize（子词切分；**拼接边界的切分可能与单独编码不同**，且影响前缀缓存块对齐）→ 嵌入查表（token 内容与冻结权重的唯一交互点）→ 逐层前向。**[V]**
**写入**：生成式写入（一次 LLM 推理）或零成本被动记录。写入形状由设计者决定，无形态约束。
#### 4.1.2 成本：完整账单
逐次读取付费，账单四项（原文献常漏第一项）：
1. **检索**：查询嵌入（一次短前向）＋ ANN 检索（HNSW 类，~对数跳数，索引内存与向量数同阶）＋ 可选 rerank（每候选对一次 cross-encoder 前向）。大库场景下此账单项可与注入同阶甚至主导。**[V]**
2. **prefill**：注意力计算随注入长度 L 二次增长，投影项线性。**[V]**
3. **解码期注意力**：每步对全部 L 个缓存键线性。**[V]**
4. **摊销机制**：重复前缀（固定系统前缀、固定记忆块）的 prefill 产物可复用；其物理实现是把重复内容物化为 latent 副本（见 §6.2 前缀缓存行）。多家推理服务商的前缀缓存产品即此机制。**[R]**
准确表述：**逐次计费，重复前缀可经 latent 物化摊销**。
#### 4.1.3 优势、失败模式、攻击面
**优势**：内容人可读，任意粒度可审计/编辑/删除/比对（合规操作如按用户删除的物理基础）；模型无关（换底座后文本仍可注入）；生效范围逐请求组装。
**失败模式**：选择失败（相关条目未被选中）、注入失败（噪声占预算、注意力稀释）、内容失败（过时、条目间冲突、抽取损失）。全部可定位到具体条目与决策——可归因、可定向修复。
**攻击面**：注入内容直接进入前向计算，外部可控文本可经记忆库进入——记忆投毒、经记忆通道的提示注入；持续投毒内容可传播至未来会话。**[C]**（传播性主张源于单一未验证文献）
#### 4.1.4 表达能力：两侧在场的开放争议
这是 token 通道最重的未决问题，本文并列三条文献线：
**限制线**。Petrov & Bibi（2024）**[V]** 在简化注意力模型上证明：前缀微调以固定方向偏置注意力输出、不能改变对内容的相对注意力模式，因此无法学到需要新注意力模式的任务；同一理论中自由上下文比固定前缀更具表达力。适用域与外推桥须显式声明：该定理证明于（i）简化注意力模型 → 深层 Transformer；（ii）固定长度前缀 → 自由上下文（内容自适应，在直接辖域外）；（iii）特定任务族 → 通道级属性。跨越三桥的表述属外推。
**天花板线**。Xu（2026）**[C]** 主张：上下文式记忆只实现“查找”而非“学习”——agent 在没有原始笔记的情况下无法调用由该笔记获得的能力；并以 CLS 理论论证当前 agent 只实现了海马体一半。其“泛化上限可证明”之转述不含假设集，按证明规范视为未证明的强主张。
**学习线**。von Oswald et al.（2023）**[V]** 证明特定配置（线性注意力、回归任务）下 ICL 实现隐式梯度下降；Dai et al.（2023）**[V]** 给出 ICL 行为与显式微调的对应证据（隐式优化器读法）；Xie et al.（2022）**[V]** 给出 ICL 的隐式贝叶斯推断读法；Olsson et al.（2022）**[V]** 的归纳头工作支持“触发既有回路”读法。
三线并不直接矛盾（设定不同：线性模型 vs 深层网络；固定前缀 vs 自由上下文；任务族不同），但它们对同一实践问题——“基于上下文的记忆能否获得全新能力”——给出相反倾向。**诚实现状：开放，两侧形式结果的假设集不相交。**任何“token 只能诱发既有技能”的通道级断言都跨出了已证范围。
### 4.2 Latent：θ 外连续状态
#### 4.2.1 机制
**存储**：连续张量，处于模型表征空间的维度与分布内。
**写入三支**：①复用——将某次请求已产生的 KV 持久化（前缀缓存；Memorizing Transformers 的 kNN 检索式 KV 记忆 [V]）；②变换——对已有 KV 做张量操作（H2O 驱逐 [V]、SnapKV [V]、PyramidKV、KIVI 量化 [V]、Cartridges 自学习 KV 工件 [V]）；③生成——经训练的模块把 token 序列映射为记忆向量（gist tokens [V]、AutoCompressors [V]、MemGen、MemoryLLM/M+）。
**读取接口三处**：注意力入口（KV 拼接，主流）、嵌入层（软提示、记忆 token 嵌入）、层间（隐藏状态注入）。
#### 4.2.2 成本：存储算例与读取实况
**存储（数量级算例）[V]**：以 Llama-2-7B（32 层、MHA、d=4096）为例：每 token KV = 2 × 4096 × 32 = 262,144 个浮点数 ≈ 512 KiB（fp16）。100K token ≈ 50 GiB；同内容文本 ≈ 0.4 MB；比值约 10⁵（五个数量级）。架构修正：GQA（Llama-3 类，8 个 KV 头）将每 token KV 降至约 128 KiB；MLA（DeepSeek-V2 类）进一步压缩；压缩技术（量化 + 驱逐）报告 10% 级保持率 [R]。综合修正后，当前实践差距仍 ≥ 3 个数量级，且该差距是**架构与压缩技术的函数，正在收窄**。
这是六通道中唯一“保存本身构成持续运营成本”的位置（token 存储近零，parametric 无独立存储）。
**读取**：“免 prefill”成立（注入 KV 不需对源文本重付编码计算），但**保留**两项常被忽略的成本：解码期对注入键的注意力（与 token 注入同阶）＋ **KV 装载带宽**（每请求搬运的 KV 字节数与存储同阶，50 GiB 级注入意味着显著的内存流量）。净收益对长上下文、重复读取显著；对短上下文、单次读取不显著。**[V]**
#### 4.2.3 限制与版本绑定
**版本绑定**：张量数值只在生成它的权重数值与推理配置（含分块、量化、注意力实现）下有效；任一改变即失配，且失配**静默**（无错误信号）。推论：latent 记忆寿命 ≤ 模型版本寿命；跨模型无迁移机制（不同 θ 的表征空间无对应关系）。
**访问门槛**：读取要求触及推理管线内部接口；托管推理 API 通常只暴露文本输入——纯 API 部署下 latent 不可用。
**表达能力分化**（常被单格概括掩盖）：复用型（KV 拼接）与 token 同级——同为数据注入，共享 §4.1.4 的全部争议；生成/压缩型受压缩瓶颈约束，表达能力严格不高于其源内容。
#### 4.2.4 失败模式与攻击面
**失败**：分布失配（拼接来自不同上下文的 KV——位置编码错位、注意力分布漂移）；压缩失真（被压缩记忆无“页面”可翻开，损失不可检视）；静默版本失效。失败可见性介于 token（条目级）与 parametric（行为级）之间：张量级数值检测与重建探针可行，语义级诊断昂贵且非保真。
**攻击面（六通道中最裸露的注入面）**：KV 注入**绕过一切文本级安全管线**——无可扫描字符串、无 moderation 钩子；可做哈希级完整性校验，但语义级扫描机制不存在。**[V]（机制性陈述）**（实际利用难度属开放问题）
#### 4.2.5 认知对应
快权重传统（Schmidhuber 1992 [V]；Ba et al. 2016 [V]）、短时突触可塑性维持的工作记忆、以及“线性注意力即快权重编程”理论线（Schlag et al. 2021 [V]）、“注意力即现代 Hopfield 检索”读法（Ramsauer et al. 2020 [V]）均为可辩护对应物。因此“latent 在认知科学中无对应物”的断言仅在“CLS-1995 理论范围内无对应物”的意义上成立。该理论线同时预测 latent 与 parametric 在理论极限处模糊——登记为 **[P]**。
### 4.3 控制态：编排器读取的数据
**机制**：工作流状态、路由表、会话作用域状态、任务计划——跨请求持久、进入 O 的计算、不进入 f。写入由编排逻辑或 agent 自身（经工具）完成；读取为程序读取（近零成本）。存储近零（结构化数据）。
**地位**：对以编排为主要学习载体的 agent（工作流自修订、路由经验积累），这是核心记忆通道；对以 f 为唯一学习载体的 agent，它退化为配置。通道的“记忆”地位由 §2.4 判据（是否源于交互历史）逐实例判定。
**失败与攻击**：状态级可检视（同 token 的可读性）；攻击面为路由操纵与状态投毒（影响后续全部路由决策——与 token 投毒同构的持续性）。

## 5. 映射通道
### 5.1 Parametric：f 的系数
#### 5.1.1 机制：2×2 谱系
写入谱系按**写入机制 × 生效位置**为 2×2：
| | 原位（θ 内） | 附加模块 |
|---|---|---|
| **优化（梯度）** | 全量/部分微调 | LoRA、适配器 |
| **编辑（数值求解）** | ROME、MEMIT、AlphaEdit | —— |
推理时梯度更新内部模块（Titans [V]）为第三种时标：优化 + 附加/内部模块 + 推理期。读取内在于前向：权重参与每次矩阵乘法，**不存在独立读取动作**。
#### 5.1.2 结构特征
**不可分离性**：parametric 记忆的贡献与模型固有能力在计算图上无分界。这是构成性后果而非工程困难。它同样波及“预训练存量是否是记忆”的判定：由某来源获得的参数贡献无法从预训练贡献中分离——“预训练知识是记忆”与“其记忆地位被不可分离性削弱”只能同时以弱化形式成立。**[A]**
**定位的争议**：知识编辑文献曾报告 FFN 中间层的因果定位（Geva et al. 2021 键值结构 [V]；Dai et al. 2022 知识神经元 [V]；Meng et al. 2022 因果追踪 [V]）。Hase et al.（2023）**[V]** 报告：因果定位结论不能预测最佳编辑位置——不同干预方式给出的关键位置不一致。现状：定位是统计意义上的近似聚集，不是可依赖的精确地址；“定位精度足以指导编辑”仍是开放问题。
**无地址性的不对称**：写入方向近似可定向（单事实定向写入已有工程实现）；删除方向近不可定向（“抹除特定事实而不伤其他”无稳定算子）。
#### 5.1.3 成本与适用域
**读取成本**：θ 内原位修改为零边际（生效成本已在必经前向内）；**附加模块非零**——LoRA 的 A·B 矩阵乘是每 token 额外 FLOPs。**[V]**
**写入成本**：优化谱系付数据构造、训练算力、回归评测；编辑谱系付定位、求解、副作用检查。顺序编辑的叠加退化使成本随编辑次数超线性增长。**[V]**
**“买断制”适用域**：读零边际、写一次性仅对**静态知识、低频变化、高频读取**成立。agent memory 的核心场景恰是持续经验积累——恰在适用域外。
**生效全局性**：θ′ 对此后经此权重的所有请求生效；多租户需每租户独立实例。
**可迁移性**：记忆即模型本体，跨 θ 不保持；但 LoRA 跨同架构基座可迁移，跨架构迁移是活跃前沿。**[V]**（对附加模块位置成立，对原位位置不成立）
#### 5.1.4 失败模式与攻击面
**失败**：灾难性遗忘（写入损伤存量行为）；牵连效应（改事实 A 而关联推理不跟随）；顺序叠加退化。共同特征：**失败不可见**——数值中无条目无页面，只能行为级回归观测。
**攻击面**：编辑面滥用——恶意编辑构成持久且不可见的行为后门；供应链投毒（模型/适配器分发链）。失败不可见 + 可定向写入的组合使此通道成为静默持久修改通道。
#### 5.1.5 判据注记
LoRA 归 parametric 而非 latent 的根本理由：新增的是**系数**（参与矩阵乘法），不是**数据**（被注意力读取）。此判据与“生效位置在权重”相比更深一层，且统一裁决软提示（§6.2）。
### 5.2 解码态：D 的规则
**机制**：持久化解码约束组件——JSON schema 强制、语法约束解码、logit bias、工具调用格式。商用推理 API 已将约束解码作为一等功能（Willard & Louf 2023 给出高效实现 [V]）。它们满足记忆判据（持久、在 D 处重入计算、直接塑造输出支持集）；按 §2.4，交互历史修订产生的 schema 为记忆，authored 静态 schema 为配置。
**成本**：写入为声明（近零）；读取近零（内在于解码步）；存储近零。
**信息类别**：形式知识（合法输出长什么样），与内容通道互补；在内容通道不可用时（生成格式约束）不可替代。
**安全注记**：控制约束者控制输出空间——约束通道同时是审查通道与注入通道（强制结构亦可强制内容子空间）。
**边界声明**：按 §3.3 自检第 2 条，logit bias 的数据/映射归属是弱判定；schema 作为规则归映射较无争议。
### 5.3 程序：O 的映射
**机制**：运行中习得的程序——技能库（Voyager [V]：运行时生成的代码技能、以代码文本存储、按需装载后**执行**）、工作流修订、习得的编排策略。
**此处是“角色 ≠ 基底”的单点例证**：存储实例为 token 形态（离散符号、数据），功能角色为映射（装载后执行、构成过程）。基底分类必须按存储归 token，并因此丢失其映射功能；角色分类按读取时身份归程序通道。两种读法各有所得，取舍见 §11.3。
**成本**：写入经 LLM 辅助代码生成（便宜、增量）；读取 = 执行成本（环境相关）；存储近零。**失败**：执行错误可见、可复现——可检视性同 token。**攻击**：恶意技能注入 + 代码执行通道（活跃攻击面）。

## 6. 桥：跨通道现象
### 6.1 定义
**桥 = 写入通道与读取通道不一致的持久状态。**同一信息可持多个物化实例，各实例可属不同通道；记忆的生命周期是实例的迁移轨迹，不是单一形态的驻留。**[A]**
### 6.2 桥上居民
| 现象 | 写通道 | 读通道 | 性质 |
|---|---|---|---|
| 前缀缓存 | token（源文本） | latent（KV 副本） | 摊销：重复内容物化为 KV；按 §2.3，副本为可再生投影 → 缓存 |
| 软提示/前缀微调 | parametric（优化器写入连续参数） | latent 接口（以连续向量注入嵌入位） | 归属争议的结构性来源：问“它是什么形态”问错了问题；按写入归 parametric 谱系、按读取走 latent 接口。PEFT 文献主流按优化器行为归“参数化微调”**[V]**；接口视角归 latent。两读法均有文献支撑 |
| Titans | parametric（推理时梯度更新模块参数） | parametric（系数身份、快时标） | fast-weights 的工程实例——数据-映射桥的理论居民；框架预测该类对象的归属争议必然出现 **[P]** |
| Voyager 技能 | token（代码文本） | 程序（执行为映射） | 数据存储承载映射功能 |
| 多模态上下文 | 映射（视觉/音频编码器为习得映射） | 数据（编码器输出作为嵌入注入） | 编码器写、数据面读；三形态框架下通常笼统计为“token” |
| 巩固（蒸馏/replay/sleep-time） | token（经验文本）→ parametric | — | data→map 迁移；CLS replay 的工程对应（§9.4） |
### 6.3 对既有归类争议的裁决规则
**归属按读取时角色判定；写入通道单列。**此规则的代价与收益：代价——单一名词归类的便利丧失（“它是什么”需要两元组回答）；收益——归类争议转化为判据选择问题，可显式讨论。
### 6.4 边界案例裁决表：两框架并列
| 案例 | 三形态框架 | 通道框架 | 分歧来源 |
|---|---|---|---|
| 请求内 KV cache | 非记忆（执行结构） | 非记忆（本次计算的循环态） | 一致 |
| 跨请求持久 KV（可再生） | latent 记忆 | latent 缓存（权威副本判据） | 缓存/记忆判据层不同 |
| 自学习 KV 工件 | latent 记忆 | latent 记忆（KV 为权威本体） | 一致 |
| 软提示 | parametric（PEFT 主流）或 latent（接口视角）——文献分歧 | 写 parametric / 读 latent 的桥 | 三形态单名词无法装下双通道事实 |
| Titans | parametric 或 latent——文献分歧 | parametric（推理期系数写入） | 同上 |
| Voyager 技能 | token | 写 token / 读程序 | 基底分类丢功能角色 |
| 解码约束 | 视野外（控制面排除） | 解码态 | 分析单位差异 |
| 编排状态 | 视野外 | 控制态 | 同上 |
| 多模态注入 | token（笼统） | 编码器（映射）写 / 数据面读 | 桥视角给出更细结构 |
读法提示：该表不预设哪列更优——它展示的是：**分歧多源于判据与单位选择，而非事实分歧**。评价两列的取舍标准见 §11.3。

## 7. 经济学与容量定律
### 7.1 加性容量与竞争性容量
**数据通道是加性资源**：外置存储近无限，新增记忆不损害既有记忆的存储级完整性（检索干扰属操作层，不损坏条目本身）。**映射通道是竞争性资源**：θ 容量固定，新写入与存量写入在同一容量上分配。
联想记忆容量律（Hopfield 1982 [V]：稠密二值网络容量 ~0.14n；稀疏编码显著提升）是此现象的经典理论对应；深度网络上的“知识容量标度”（如 2 bit/参数量级的报告 [R]）是经验锚点。**须声明：容量律向 LLM 的外推是类比映射，非定理应用**——LLM 的分布式知识容量问题远比 Hopfield 模型复杂。
由此三条推论：
1. **巩固必须选择性**——它是容量分配问题，不是速度匹配问题（这比“快慢互补”的现象级表述更深一层：即使写入无限快，容量约束仍迫使选择）；
2. **映射通道失败结构性全局**——容量竞争无局部性，牵连效应是其表现；
3. **数据/映射分工的必然性以容量比率为条件**——若出现无干扰的参数化写入（容量律被违反），分工重开。**[AC]**
### 7.2 中心交易
**数据通道：按次付费，换无干扰与无限容量。映射通道：一次性买断，换零边际读取，付全局竞争与写入成本。**此为给定机制的分析性推论 [A]；其量级参数（检索成本、KV 压缩比、编辑退化率）为经验值，量级变动改变工程结论。**[E]**
粗粒度收支平衡：写入成本 W 的 map 通道实例与读成本 c_r/次的数据实例相比，访问次数超过 W/c_r 后 map 更省——但须叠加更新频率惩罚（map 更新干扰存量，数据更新无干扰），故高频更新场景平衡点右移甚远。此不等式的实证标定是开放问题（§12）。
### 7.3 摊销与物化
重复读取的数据内容，其摊销的物理实现是**跨通道物化**（token 副本 → latent KV 副本）。何时物化的最优策略（命中率 × 节省 vs 存储 × 失效风险）是推理服务层的活跃工程问题，本文登记为桥经济学，不展开。**[R]**

| 量 | 数值 | 条件 |

## 9. 认知科学参照
**声明**：本章映射是参照系工具而非证据；其价值判据是解释力增益，非对应物存在本身。CLS 是被选参照系之一，不等于认知科学全部。
### 9.1 CLS：两半都取
McClelland, McNaughton & O'Reilly（1995）**[V]** 的原始论证含两个互补半边：**速度互补**（海马快、新皮层慢）与**容量-泛化互补**（海马高容量稀疏编码、逐条可分离；新皮层有限容量、分布式结构化、泛化强）。2020 年更新（McClelland et al., Trends in Cognitive Sciences）**[V]** 融合了机器学习视角，巩固了“互补系统”读法。
映射：数据通道 ↔ 海马角色（加性、情景、逐条）；映射通道 ↔ 新皮层角色（竞争、语义、泛化）。相比“token↔海马、parametric↔新皮层”的表层对应，容量半边额外解释两件事：巩固为何必须选择（容量分配）、映射失败为何全局（竞争无局部性）。
latent 的认知对应为快权重线（§4.2.5）——在 CLS-1995 内无对应、在认知科学整体内有候选。
### 9.2 ACT-R：陈述性/程序性
Anderson 的 ACT-R **[V]** 区分陈述性记忆（chunk + 激活扩散检索）与程序性记忆（产生式规则）。映射：token + 检索、控制态 ↔ 陈述性；解码态、程序通道 ↔ 程序性。此映射的价值在处理“token 类内部异质性”：事实/技能/程序/编排状态混装于单一基底类，不是分类粒度问题，而是**基底分类原理上不承载角色区分**——角色轴（陈述/程序）与基底轴（离散/连续）本就正交。
### 9.3 映射的载荷分级
| 映射 | 载荷 |
|---|---|
| 数据/映射 ↔ 陈述/程序（ACT-R） | 结构同构：角色级区分，双向映射 |
| 数据/映射 ↔ 海马/新皮层（CLS） | 半同构：容量-泛化半边提供机制解释 |
| latent ↔ 快权重 | 理论线支持（Schlag et al.），预测 latent/parametric 极限模糊 [P] |
| token ↔ 海马 | 表层类比：速度与可分离性对应，容量机制不在 token 侧成立 |
### 9.4 巩固：工程现状与缺口
CLS 的 replay（海马内容重放训练新皮层）已有工程对应物：系统提示蒸馏入权重（Llama 3 报告提及长系统提示蒸馏 [R]）、经验回放微调、sleep-time compute（Letta 类后台巩固 [R]）。
**精确缺口是闭环而非通道**：通道存在（token → parametric 的蒸馏/回放管线），缺失的是 agent 运行内**自动、持续、选择性**的 data→map 迁移。开放问题有二：**选择策略**（什么值得巩固——容量分配问题，§7.1）与**迁移安全**（被投毒记忆经巩固即永久固化——迁移本身是投毒固化通道；此攻击面在纯数据通道下不存在等价物，因为数据条目可删除而参数贡献不可分离）。

## 10. 失败模式与攻击面总表
| 通道 | 主要失败模式 | 可见性 | 主要攻击面 |
|---|---|---|---|
| token | 选择失败、注入稀释、内容过时/冲突 | 条目级可归因 | 记忆投毒、提示注入、跨会话传播 [C] |
| latent | 分布失配、压缩失真、静默版本失效 | 张量级可检测，语义级难 | 绕过文本级安全管线 |

## 11. 框架的能力、限度与比较
### 11.1 能做什么
分类当前已部署的全部状态机制（含既有框架视野外者：解码约束、编排状态、技能库）；将归类争议从“无共识”推进到“判据选择可显式讨论”（§6.4）；描述记忆生命周期为迁移轨迹（§6）；给出容量驱动的数据/映射分工推导（§7.1）；发出可检验预测（桥上居民聚集 [P]、latent/parametric 极限模糊 [P]、攻击目标向映射通道漂移 [P]）。
### 11.2 不能做什么
裁决“检索是否构成学习”（§4.1.4：开放，两侧假设集不相交）；提供跨通道通用度量衡（评测协议仍高度分离：多轮对话召回 vs 编辑三指标 vs 压缩比与长程检索）；宣告自身的地基有经验内容（数据/映射二分为 [A]，价值全在二层枚举与三层经济学的组织力）。
### 11.3 与三形态框架的公平比较
| 维度 | 三形态 | 通道（本文） |
|---|---|---|
| 概念负担 | 低（三名词、一轴） | 高（两轴六通道 + 桥） |
| 文献检索性 | 高（既有综述词汇，可检索、可对齐社区） | 低（词汇尚未流通） |
| 产品级选型 | 多数场景足够 | 增益有限 |
| 边界对象裁决 | 登记为无共识 | 给出判据与双通道事实描述 |
| 生命周期描述 | 无对应概念 | 桥与迁移轨迹 |
| 经济学推导 | 现象级罗列 | 容量-竞争推导（加法/乘法结构） |
| 覆盖面 | f 的三个输入位置 | 管线五面（含 D、O） |
| 自身弱点 | 轴混合两层面（数据基底 + 映射通道并列）；控制面视野外 | 枚举条件于 O∘D∘f 分解（且 O 可递归实现）；D 面判据弱；词汇未流通 |
结论的诚实形态：**两框架是不同分辨率工具，非竞争性真理主张。**多数工程决策三形态足够；边界对象、生命周期、容量经济学、编排型 agent 恰是通道框架的付费区。替代读法亦在场：可将通道框架读作三形态的精细化（保持三形态为一级词汇、通道为二级分析），此读法牺牲部分覆盖声明、换取文献兼容性——读法选择由使用目的决定。
### 11.4 证伪条件汇总
1. 出现不可归约于六通道的新干预面 → 枚举证伪；
2. 边界案例裁决质量劣于三形态（§6.4 表无法减少争议）→ 数据/映射轴按 §3.3 判据弃用；
3. 规模化无干扰参数化写入 → 容量律违例 → 数据/映射分工推导重开；
4. KV 压缩至与文本同数量级 → token/latent 经济学合并；
5. 桥上居民停止聚集（跨通道系统不再增长）→ 桥概念丧失预测对象。

## 12. 开放问题
1. **检索是否构成学习**：形式化正面挑战；两侧形式结果假设集不相交，需统一设定下的直接对比（§4.1.4）；
2. **跨通道度量衡**：统一评测协议，使数据/映射通道可同尺度比较；
3. **巩固闭环**：选择策略（容量分配的在线算法）＋ 迁移安全（巩固前的投毒检测）；
4. **无干扰参数化写入**：容量律违例的系统搜索（连续学习母学科的开放前沿）；
5. **latent 压缩至文本同阶**：数量级突破将合并两条数据通道经济学；
6. **latent 语义级安全扫描**：对注入 KV 的内容级审核机制（当前不存在）；
7. **编辑定位精度**：因果定位与最佳编辑位置的鸿沟（Hase et al. 之后仍开放）；
8. **跨架构 latent 迁移**：表征空间对齐问题；
9. **顺序编辑退化定律**：退化的定量规律与编辑链长度上限；
10. **投毒跨通道传播动力学**：token → 巩固 → parametric 的传播模型与检测点；
11. **物化最优策略**：何时将重复数据物化为 latent 副本的在线决策问题；
12. **收支平衡不等式的实证标定**：W/c_r 的实测与更新频率惩罚的量化。

## 13. 结语
问题的物理起点是一个无状态函数与一个需要状态的 agent 之间的落差。弥合落差的一切机制，最终是让持久信息以某种身份重新进入计算：作为被读取的数据，或作为构成计算的映射；进入模型、解码器或编排器；以离散符号、连续张量、参数值、规则或可执行程序为基底。载体决定成本结构与失败可见性；角色决定容量经济学与干扰定律；桥决定记忆的生命周期形态。
既有三形态分类正确刻画了 f 的三个输入位置，是多数工程决策的足够工具。通道框架在其上加装了角色轴与管线面，付费区在边界对象、生命周期与容量推导处。两框架的取舍由用途决定，其证伪条件均已登记。
认知参照系给出的最深的单一提示仍是巩固缺口：data→map 迁移的自动闭环——选择什么、何时迁移、如何保证迁移安全——是当前工程层真正的开放前沿。它不是分类学可以回避或弥补的问题；分类学能做的全部，是把它定位清楚。

## B.7 术语表
- **通道**：持久状态进入计算的（角色 × 管线面）位置，本文一级分类轴；
- **基底**：状态的物理材料类别（离散符号 / 连续张量 / 参数值 / 规则 / 代码），二级词汇；
- **实例**：同一信息内容的一个物化副本，可多存、可异基底；
- **桥**：写通道 ≠ 读通道的持久对象（§6）；
- **权威副本**：删除即永久信息损失的实例（§2.3）；
- **数据 / 映射**：被固定过程读取的状态 / 构成过程本身的状态（§3.3）；
- **巩固**：data→map 的迁移过程及其工程对应物（§9.4）；
- **形态（遗留词）**：三形态框架的 token/parametric/latent，本版中重新表述为“数据通道两基底 + 映射通道之一”。
