# 记忆的通道：Agent Memory 的载体形态学
## 0. 导言
一个以大语言模型为计算核心的 agent，其计算单位是函数 f_θ(x)——给定权重 θ 与输入序列 x，产生输出分布。函数本身无状态：两次调用之间，除非信息被显式地从一次调用携带到下一次，否则两次调用在因果上独立。多轮对话中上轮内容影响本轮输出，不是因为模型"记得"，而是系统把上轮文本重新拼入了本轮输入。
这是 agent memory 问题的物理起点：**LLM 本身是无状态的，但 agent 需要跨调用地利用信息**。弥合这个落差必须回答两个问题——信息被存在哪里，以及信息如何重新进入计算。
第二个问题的答案有限：一切影响 LLM 输出的途径最终都必须经过模型的前向计算。对前向计算的信息进入面做枚举，当前 Transformer 架构下收敛为三个位置——输入 token 序列（经嵌入查表进入）、参数值（作为计算系数参与）、中间激活（可作为外部注入的连续向量参与）。任何记忆机制，无论工程上多复杂，其持久状态最终必须以这三种物理形式之一安放。
但这一枚举作为**起点**存在抽象层级的误置。三个位置是当前架构下通道的一种收敛结果，不是跨架构不变的出发点。更根本的第一性约束是**信息通道**——下文第 1 节给出其形式定义。三形态框架因此不是被推翻，而是被降维安放：它准确描述了通道进入位置维度在当前架构下的收敛，但"形态"这一概念把状态的物理本体与状态的管理操作压在一根轴上，是多数归类争议的根源。
本工作的定位是：在 Hu 等（2025）与 Tang 等（2026）独立提出的 Forms 轴共识基础上，以通道五元组重构分析起点，对三种通道各自的机制、代价、争议与边界做系统性的重新审视，并以 Complementary Learning Systems 理论作为部分映射的启发源（而非独立参照系），检验通道框架的解释力与盲区。本工作不宣称发现新分类，致力于把已知分类做到机制层的诚实。

## 1. 第一性原理：信息通道与计算边界
### 1.1 信息通道的形式定义
**定义 1（信息通道）**：一条信息通道 C 是一个五元组 (E, P, T, S, M)：
- **E（entry，进入位置）**：信息进入计算图的物理位置——输入边界、计算内部（中间激活注入）、计算系数；
- **P（persistence，持久化边界）**：信息在通道中存活的时间尺度——单请求（请求结束即销毁）、跨请求（持久）、跨版本（随权重存活）；
- **T（temporal granularity，时间粒度）**：信息生效的时间粒度——逐 token、逐请求、逐权重版本；
- **S（scope，作用域）**：信息影响的范围——单会话、单用户、全局；
- **M（mutability，可变性）**：信息在通道内被修改的机制与成本。
**定义 2（计算边界）**：本文的分析单位为"一次 LLM 前向调用"。该边界的选择本身即是定义选择——若改为"一次 agent 任务"或"一个权重版本的生命周期"，同一信息可被归入不同通道。分析单位必须显式声明，不存在默认正确的选择。
**核心命题（通道约束）**：任何持久状态必须经至少一条通道进入前向计算才能影响输出。当前 Transformer 架构下，通道按 E 收敛为三类：**输入边界通道（token 形态）、计算系数通道（parametric 形态）、计算内部注入通道（latent 形态）**。但 E 只是五元组之一；P、T、S、M 上的差异可以在同一 E 内部产生截然不同的记忆系统。
### 1.2 通道框架相对"三位置"框架的增益
通道重构的直接收益在于：多数传统"边界案例"不再需要逐个裁决，而是自然落入矩阵的不同单元格。
**软提示的归属**。软提示在 E 上为嵌入位注入（latent 侧），但在 P（跨版本）、T（逐请求）、M（梯度优化）上与 LoRA 一致。主流 PEFT 文献将其视为参数化微调——可训练参数在优化器下更新，与 LoRA 无本质差异；Petrov 与 Bibi（2023）的理论分析进一步把 prefix-tuning 表述为"受限的参数化通道"而非独立形态。两种归类在通道框架下不再是冲突，而是同一系统在 E 与 M 两个维度上的不同投影——争议的根源是只看一个维度不看其余四元。
**Titans 类在线记忆模块的归属**。Titans（Behrouz 等，2025）在推理时以梯度更新内部记忆模块参数。按"状态物理类别"判，E 为系数通道（parametric 侧）；按"操作上表现为推理期产生的状态"判，T 为逐请求（latent 侧的操作特征）。通道框架下它是**系数通道上的高时间粒度变体**，不需要强行归入"parametric 或 latent"的二选一。
**请求内 KV cache 与跨请求持久 KV**。两者在 E 上相同（计算内部注入），在 P 上不同（单请求 vs 跨请求）。前者是执行结构（自回归解码中前文投影的复用机制），后者满足记忆判据。判据从"操作层争议"变为 P 维度的取值差异，不再需要逐案裁决。
### 1.3 枚举的诚实表述
通道按 E 的三分是**当前 Transformer 架构下的事实性收敛，不是普适定理**。若底层架构改变（非 Transformer、混合架构、扩散语言模型），E 维度的收敛结果随之改变，而"通道约束"这一分析框架保持有效。控制面信息（路由、编排、采样配置）不改变前向计算的信息内容但对系统结果影响显著——其在通道框架下的处理见第 2.3 节。

## 2. 分析单位的显式分层
### 2.1 三层结构
**形态层**：状态的本体类别——离散符号、连续张量、参数值。对应通道的 E 维度。
**操作层**：状态的管理机制——选择、注入、更新、淘汰、作用域、治理。对应通道的 P、T、S、M 维度。
**系统层**：agent 的整体架构——多模块协作、控制流编排、子 agent 通信。
### 2.2 分层判据
一个争议是形态层还是操作层问题，判据是：**改变该属性是否需要改变状态的物理载体**。
**缓存与记忆**：同一 latent 载体既可承载缓存（静态内容、无条件读取——系统前缀的 KV 副本），也可承载记忆（动态内容、查询参数化读取——kNN 检索后的 KV 拼接）。改变的是操作层，故为操作层区别，非形态层区别。
**RAG 与 token 记忆**：检索对象是外部静态语料还是 agent 自身经验，物理载体同为离散符号库。但后者的写入-更新-淘汰生命周期使它在 P 与 M 维度上构成完整记忆系统。这提示"RAG 与记忆的区别"不是单一的形态层或操作层问题，而是**操作层完整性的程度问题**——一个只有检索没有更新与淘汰的系统是 RAG，一个具备完整生命周期的系统是记忆，两者之间是谱系不是二分。
### 2.3 控制面的正面处理
路由、编排、采样配置不进入前向计算的信息内容，但显著影响系统结果。本文对控制面的处理是：控制面信息若以离散符号存在（编排规则文本、工具调用记录），已在 token 通道覆盖范围内；若以代码/权重存在（编译后的编排逻辑），已在 parametric 通道覆盖范围内；若以向量存在（learned router 的激活），已在 latent 通道覆盖范围内。
**控制面不是被三形态排除的第四形态，而是三形态的一个应用域。** 对以编排为主要学习载体的 agent，控制面记忆的形态学分析与经验记忆的形态学分析适用同一框架——区别在于哪些操作层组件（作用域、治理、版本管理）在控制面域上更重要，而非形态层需要新类别。

## 3. 生命周期 × 通道矩阵
工程选型的真实决策变量不是"用什么形态"，而是"在哪个生命周期阶段付什么成本"。本节以生命周期阶段 × 通道为矩阵主轴。
| 生命周期阶段 | token 通道 | parametric 通道 | latent 通道 |
|---|---|---|---|
| **写入** | 一次生成调用（秒级）或零成本被动记录 | 梯度优化（小时-天级算力）或编辑（定位 + 求解 + 副作用检查） | 复用（近零成本）／变换（驱逐/量化，秒级）／生成（训练好的模块，推理期一次前向） |
| **存储** | 近零（文本约 0.4 MB / 100K token） | 无独立存储（即模型本体） | 重——持续驻留（见 6.2 量化） |
| **读取（每次生效）** | 注入 + prefill 重编码 + 注意力，逐次付费 | 零边际（内在于必经前向） | 免 prefill，保留解码期注意力成本 |
| **更新/淘汰** | 条目级增删改，近零成本 | 灾难性遗忘风险，顺序编辑叠加退化 | 压缩失真，重建成本高 |
| **失效** | 模型更换时文本仍可注入 | 即模型本体，不存在"失效" | 权重或推理配置变更后静默失效 |
| **审计/治理** | 条目级完全可检视 | 行为探针唯一通道 | 张量级可检测、语义级诊断难 |
矩阵的核心洞见：**三种通道的成本经济学不在同一生命周期阶段上占优**——token 在写入端最便宜、读取端最贵；parametric 在读取端零边际、写入端最贵且退化累积；latent 在读取端免 prefill、存储端构成持续运营成本。三者的交汇点及其物理解释见第 8 节。

## 4. Token 通道：外部符号记忆
### 4.1 机制
**存储**：离散符号序列，存放于模型外任意介质——文件系统、关系库、图库、向量库的文本字段。物理上与模型部署完全解耦。任何能产出文本的系统都可以写入（agent 自身摘要、环境日志、用户输入）。
**读取**：完整计算链为——选择（从库中选出子集）→ 序列化（条目转字符串）→ 组装（与系统指令、查询拼接）→ tokenize（子词切分，拼接边界处的切分可能与单独编码不同）→ 嵌入查表（token 读取与冻结权重的唯一交互）→ 逐层前向。
### 4.2 成本结构
**写入便宜**：一次 LLM 推理调用（生成式写入）或零成本被动记录（环境日志）。
**读取逐次付费**：每次生效都需重付后半段计算——prefill 的注意力计算量随注入长度二次增长，解码期每步对全部缓存键的注意力随注入量线性增长。同一记忆被读取一千次，支付一千次注入计算。
**摊销机制存在且经 latent 实现**：注入内容跨请求重复时（固定系统前缀、固定记忆块），推理系统可缓存其 prefill 产物并在后续请求复用。该摊销的物理实现是把重复内容物化为 latent 副本——**这是 token 通道向 latent 通道的经济学逃逸，不是 token 通道自身的属性**（详见 8.1 节）。
### 4.3 优势
- **完全可检视**：内容人可读，可在任意粒度阅读、编辑、删除、比对——条目级审计、版本管理、合规操作（如按用户删除）的物理基础。
- **模型无关**：换用不同权重与 tokenizer 的模型后文本仍可注入；记忆资产存续不依赖模型版本。
- **生效范围逐请求组装**：注入什么、注入多少由每次请求决定。
### 4.4 能力上限的机制刻画与外推边界
**Petrov 与 Bibi（2023）的理论结果**是本通道最重要的机制层证据：context-based fine-tuning（含 prefix-tuning、soft prompting）在表达能力上严格弱于完整微调，即使参数量相同——前缀只能以固定方向偏置注意力输出、不能改变对内容的相对注意力模式，因此无法学到需要新注意力模式的任务。
**该结论的外推边界必须显式声明**。它刻画的是"注意力模式层面"的上限：直接蕴含"token 注入不能改变相对注意力模式"，但不直接蕴含"token 只能诱发既有技能"——后者需要额外论证"是否存在不依赖新注意力模式的新技能"。若存在这类技能（例如仅需事实性知识注入、无需新注意力结构的任务），token 通道在其上不受 Petrov-Bibi 上限约束。这一步在多数引用该理论的工作中被跳过，本文登记为开放问题。
### 4.5 失败模式与攻击面
失败集中而可见：选择失败（相关条目未被选中）、注入失败（噪声占预算、注意力稀释）、内容失败（过时、条目间冲突、抽取损失）。全部可定位到具体条目与具体决策——可归因、可定向修复。
**推理期攻击面**：注入内容直接进入前向计算，外部可控文本可经记忆库进入——记忆投毒、经记忆通道的提示注入。持续性记忆投毒是结构性脆弱点：被投毒的内容会传播至未来所有会话。
**T-Mem（2026）对选择失败的结构性刻画**：主流长期记忆系统共享同一相似度瓶颈——"reachability-bounded by similarity"，当查询与记忆条目既不共享措辞也不共享主题时（associative 检索情形），集体失败。其回应是在写入时预计算额外检索线索（Entity / Bridge / Horizon / Scene 四类触发器族），使记忆"anticipates, not archives"。这一工作既是对 token 通道选择组件的批评，也暗示**检索本身可能需要形态级创新而非纯操作层改进**——与第 7 节的正面讨论直接相关。

## 5. Parametric 通道：权重记忆
### 5.1 机制
**存储**：记忆状态即参数取值的一部分——存于 θ 本身（原位修改）或附加于其上的参数模块（LoRA、适配器、旁路网络）。读取内在于前向计算：权重参与每次矩阵乘法，不存在独立的读取动作。
**写入**：两个谱系。**优化**（梯度）——构造训练信号迭代更新，写入结果的形状由优化动力学决定；**编辑**（直接数值修改）——先近似定位，再求解约束修改（ROME、MEMIT、AlphaEdit 等）。
### 5.2 内部异质性的显式分拆
本通道内部存在被传统处理压缩的关键差异。本文分拆为两个子类：
**存量参数（预训练）**：
- 可迁移性：记忆即模型本体，跨模型无迁移；
- 可审计性：无独立通道，行为探针是唯一访问方式；
- "预训练知识是记忆"的主张因不可分离性（记忆贡献与模型固有能力在计算图上无对应分界）只能弱化成立。
**增量参数（微调 / 适配器 / 编辑产物）**：
- 可插拔、可回滚（LoRA 类物理形态）；
- 写入成本：数据构造 + 训练算力 + 回归评测（优化谱系）；定位 + 求解 + 副作用检查（编辑谱系）；
- 生效全局性：此后经此权重的所有请求生效——所有用户、所有会话共享；多租户需每租户独立权重实例或独立适配器实例。
**分拆的必要性**：两类子类在可迁移性、可审计性、写入成本结构上差异巨大。将其压为同一形态的变体，导致"parametric 记忆不可审计"这类全称判断在增量子类上不成立（LoRA 可插拔即部分可审计），在存量子类上成立。工程选型与理论分析都应区分对待。
### 5.3 定位争议与 AlphaEdit 争论链
知识编辑文献曾报告 FFN 中间神经元对事实的因果定位（Geva 等 2021 的键值结构；Dai 等 2021 的知识神经元；Meng 等 2022 的因果追踪）。但 Hase 等（2023）报告：**因果定位结论不能预测最佳编辑位置**——不同干预方式（去噪式与反事实式）给出的关键位置不一致。"better mechanistic understanding may not always translate to insights about how to best change behavior"。定位是统计意义上的近似聚集，不是可依赖的精确地址。
**AlphaEdit（2024/2025）提供了绕过精确定位的工程路径**：不追求精确地址，而将扰动投影到保留知识的零空间，理论上保证对保留知识的输出不变。实验上使多数 locate-then-edit 方法平均提升 36.7%。
**争论链的后续发展（2026）**：EvoEdit 提出顺序零空间对齐以缓解连续编辑下的灾难性干扰；SonoEdit 将零空间约束编辑推广到 TTS 模型的发音修正；同时已有可复现性研究对 AlphaEdit 类方法的鲁棒性提出质疑。该链条（精确定位不可靠 → 零空间绕开定位 → 零空间方法的鲁棒性被质疑 → 顺序对齐的进一步修正）构成本通道当前最重要的活跃前沿。
### 5.4 成本与适用域
**读取零边际**——生效成本已包含在必经的前向之内。
**"买断制"的适用域限定**：读零边际、写一次性的表述仅对**静态知识、低频变化、高频读取**成立。agent memory 的核心场景恰是持续经验积累：顺序编辑的叠加退化使成本随编辑次数超线性增长。EvoEdit 的顺序对齐正是针对这一退化，但其长期稳定性仍属开放问题。
### 5.5 失败模式
灾难性遗忘（写入损伤存量行为）；牵连效应（修改事实 A 而关联推理不跟随）；顺序叠加退化（每次编辑污染上次）。共同特征：**失败不可见**——数值中无条目、无页面，只能行为级回归观测。

## 6. Latent 通道：持久张量记忆
### 6.1 机制
**存储**：连续张量，存在于模型外但处于模型表征空间的维度与分布内。写入谱系分三支：
1. **复用**——把某次请求已产生的 KV 持久化（前缀缓存、Memorizing Transformers 的 kNN 检索式 KV 记忆）；
2. **变换**——对已有 KV 做张量操作（H2O 的驱逐、SnapKV、PyramidKV、KIVI 量化、KV Packet 的自蒸馏对齐）；
3. **生成**——经训练的模块把 token 序列映射为记忆向量（gist tokens、AutoCompressor、MemGen、Cartridges）。
**读取**：注入点覆盖前向计算的三个阶段——注意力入口（KV 拼接，主流形态）、嵌入层（软提示、记忆 token 嵌入）、层间（隐藏状态注入）。
### 6.2 存储成本的量化
这是三通道中唯一"保存本身构成运营成本"的位置：
- Llama-2-7B 每 token 约 512 KB 的 KV（fp16），100K token 约 51 GB，对照同一 100K token 的文本约 0.4 MB——**差 5 个数量级**；
- Llama 3.1 8B 在 128K 上下文时 KV 达 17.12 GB，超过模型本体 16.06 GB——**KV 超过权重本身**；
- 压缩技术（逐层预算分配、低位宽量化）持续收窄差距，有 10% 级保持率的报告，但量级差距仍保持 3 个数量级以上。
### 6.3 读取成本的准确表述
"读近零"是流行说法，准确表述是"**免 prefill、保留注意力**"——注入的 KV 不需对其源文本重付编码计算，但注入条目参与每步解码的注意力，量级与 token 注入的解码期同阶。净效果对长上下文、重复读取的内容显著；对短上下文、单次读取不显著。
**版本绑定**：张量数值只在生成它的权重数值与推理配置下有效；任一改变即失配，且失配是静默的（无错误信号）。推论：latent 记忆的寿命 ≤ 模型版本寿命；跨模型无迁移机制（不同 θ 的表征空间无对应关系）。
**访问门槛**：读取要求触及推理管线内部接口（KV 句柄、嵌入注入口）；托管推理 API 通常只暴露文本输入——纯 API 部署下 latent 不可用。
### 6.4 最新工程前沿：两项改变通道边界的工作
**Cartridges（Eyuboglu 等，2025/2026）**：对给定文档集离线训练一个小 KV cache（"cartridge"），推理时加载。Self-study 训练使 cartridge 复现 ICL 功能。量化结果：长上下文基准上匹配 ICL 性能、内存减少 38.6×、吞吐提升 26.4×；有效上下文从 128k 扩展到 484k；cartridge 可在推理时组合而无需重训。后续工作 Cartridges++ 发现了 on-context / off-context 的基本权衡——Cartridges 在文档相关查询上更好，但启发式压缩变体更好地保留了原始 LLM 处理上下文外查询（通用知识保持、指令遵循、上下文污染避免）的能力，并提出路由变体在推理时动态决策。
**机制意义**：test-time training 构成了一条介于 parametric 与 latent 之间的通道——参数化的训练过程产出 latent 形态的工件。它模糊了两通道的传统边界，也是对 CLS"新皮层巩固通道缺失"问题最直接的工程回应之一：不是把经验写回 θ，而是训练一个独立的小参数化模块产出 latent 工件。
**MemGen（Zhang 等，2025）**：memory trigger 以 LoRA 适配器形态监控推理器的隐状态序列，逐 token 计算调用概率并决定 INVOKE/SKIP；memory weaver 以当前状态为刺激生成 latent token 序列注入推理。量化结果：八个基准上超过 ExpeL/AWM 高达 38.22%，超过 GRPO 高达 13.44%。
**机制意义**：更重要的观察是**无显式监督下自发分化出 planning memory、procedural memory、working memory**。latent 通道的生成谱系不只是压缩工具——它可以是涌现认知结构的载体。这为"latent 在 CLS 中无对应物"的判断提供了新的复杂化证据：latent 通道可能自发地重建类 CLS 结构，而非停留在"第三选项"（详见第 9 节）。
### 6.5 多模态输入的归属
多模态证据（图像、音频）经视觉/音频编码器后以连续向量进入嵌入位——按 E 维度判 latent。近期工作（One Token per Multimodal Evidence）将每个多模态证据压缩为单一高维 latent token，在文本与多模态基准上保持竞争力同时大幅降低 token 消耗与存储压力。多模态 embedding 的注入构成 latent 形态的特例而非第四形态——判据是 E 维度取值，与文本 latent 注入相同。
### 6.6 失败模式
分布失配（拼接来自不同上下文的 KV——位置编码错位、注意力分布漂移）；压缩失真（被压缩的记忆没有页面可翻开，无法检视损失了什么）；静默版本失效（权重或推理配置变更后旧张量无声作废）。失败可见性介于 token（条目级可归因）与 parametric（行为级）之间：张量级数值检测与重建探针可行，但诊断成本高且非保真。

## 7. 检索是否构成学习：正面处理
本节将 v1 中登记为盲区的问题升级为正面讨论。该问题是形式化与经验性的正面挑战，分类学不可裁决，但分类学可以指出问题在不同"学习"定义下的分解。
### 7.1 Xu（2026）主张及其强度
Xu（2026）主张上下文式记忆只实现"查找"而非"学习"——agent 在没有原始笔记的情况下，无法调用由该笔记获得的能力。用 CLS 理论论证：当前 agent 只实现了 CLS 的海马体一半，缺失新皮层的慢速固化。由此导出可证明的泛化天花板：上下文式记忆在组合性新任务上的泛化有上限，且该上限无法通过增加上下文长度或检索质量突破。
**该主张的强度需要双向限定**：
**正方（支持主张）**：若"学习"定义为"权重或表征的持久改变"，token 注入确实不构成学习——内容在上下文消失后不残留。Petrov-Bibi 上限为此提供了机制层支撑。
**反方证据**：(1) HippoRAG 系列工作显示检索可以构成"continual, associative memory"——离线索引 + 在线检索的两阶段架构、以个性化 PageRank 实现关联式回忆，在行为层面上重现了海马索引理论的功能描述；(2) MemGen 的自发记忆分化显示 latent 生成谱系可以涌现出 planning/procedural/working memory 的分化——若"学习"定义为"系统行为能力的持久改变"，MemGen 的记忆模块在推理期持续改变行为，构成学习的实例；(3) Cartridges 的 self-study 训练把文档集的能力固化到小 KV 工件——这是一个介于检索与学习之间的中间形态。
### 7.2 三种"学习"定义下的分解
| "学习"的定义 | token 通道是否构成学习 | 证据/反证 |
|---|---|---|
| 权重的持久改变 | 否 | 定义上排除；Xu 主张在此定义下严格成立 |
| 表征的持久改变 | latent 生成谱系可构成；token 注入不构成 | MemGen 自发分化、Cartridges 固化 |
| 行为能力的持久改变（跨会话可调用） | 取决于记忆系统完整性 | HippoRAG 关联记忆、T-Mem 触发器族；但组合性新任务泛化上限仍开放 |
**本文立场**：检索是否构成学习，取决于对"学习"的操作定义。三种定义下答案不同——该问题是定义依赖的，不是有唯一正确答案的经验问题。分类学的贡献是显式呈现这种定义依赖性，防止不同定义下的结论被混同为矛盾。
### 7.3 T-Mem 的启示：检索可能需要形态级创新
T-Mem 的观察——现有系统"reachability-bounded by similarity"、在 associative 检索情形下集体失败——提示检索本身可能是需要形态级创新的问题，而非纯操作层改进。其四象限触发器族是在 token 通道内部对该问题的回应；MemGen 的 latent 生成是跨通道的回应。两条路径的优劣当前无跨形态通用度量衡可判（见第 10 节）。

## 8. 成本经济学的交汇点与混合必然性
### 8.1 三条交汇点及其物理解释
**交汇点一：token → latent 的读摊销**。重复注入内容的 prefill 产物物化为 latent 副本（前缀缓存），物理上是 token 通道向 latent 通道的逃逸。多家推理服务商的前缀缓存产品即此机制。AdapShot 等近期工作进一步利用语义感知的 KV 复用与位置编码解耦重编码，在 many-shot ICL 场景实现 ~10% 性能增益与 4.64× 加速。
**交汇点二：parametric → token 的写逃避**。知识编辑失败率高或退化累积严重时，工程实践退回"把该条知识写成 token 并在系统前缀注入"——用 token 的读成本换 parametric 的写风险。这是 AlphaEdit 争论链未决期间的实用策略。
**交汇点三：latent → parametric 的固化尝试**。Cartridges 的 self-study 是把 latent 工件的训练过程参数化——参数化训练产出 latent 工件，两通道在写入端融合。这是对 CLS"新皮层巩固通道缺失"问题的工程回应：不是把经验写回 θ，而是训练独立的小参数化模块产出 latent 工件。
### 8.2 "混合必然性"的论证补全
**主张**：一个同时面临高频更新、高密度消费、长期巩固的系统，在当前技术参数下必然在通道间分工。**该必然性是条件必然，不是结构必然。**
**当前经验参数表**：
- token 读成本随注入长度二次增长；
- parametric 顺序编辑退化使成本超线性增长（EvoEdit 部分缓解但未消除）；
- latent 存储成本与文本差 3 个数量级以上，但压缩技术以 10% 级保持率收窄差距。
**必然性的三项经验依赖项**：
1. 压缩保持率的提升——若达 1 个数量级以内，latent 存储劣势消失；
2. 编辑退化率的降低——若顺序编辑可稳定累积，parametric 写入优势扩大；
3. 长上下文 prefill 效率的提升——若 prefill 线性化，token 读劣势收窄。
**三项任一显著改变，"必然"重开。** Cartridges 的 38.6× 内存压缩已显示第一项的经验进展——在文档级固定语料上，latent 存储劣势已从 5 个数量级压缩到 2 个数量级以内。混合必然性的时间尺度因此可能比 v1 预估的更短。

## 9. CLS 类比的角色：从参照系到启发源
Complementary Learning Systems 理论指出，生物智能用两套互补系统解决记忆问题：海马体（快速、情景式、可分离表征）与新皮层（慢速、统计式、分布式表征）。通道框架下的映射：token 对应海马体角色（快速写入、逐条存取）、parametric 对应新皮层角色（慢速固化、分布式）。**latent 在 CLS 中无直接对应物**——它是 LLM 计算结构特有的产物（激活态的跨请求持久化）。
本文将 CLS 的角色从"独立参照系"收缩为"部分映射的启发源"，理由有三：
**第一，类比的非对称性**。latent 无 CLS 对应物，说明三通道是计算结构的产物而非认知分类的映射。既然映射是部分的，参照系的地位应相应弱化。
**第二，CLS 理论自身在持续修正**。O'Reilly 与 Norman 的后续版本、以及 Kumaran、Hassabis 与 McClelland 2016 年的更新，对原始 1995 年框架做了实质调整。用一个自身在演化的理论作为独立参照系，参照系的稳定性本身成问题。
**第三，工程系统开始自发重建类 CLS 结构**。MemGen 的自发记忆分化、Cartridges 的离线固化 + 推理加载分工，提示 CLS 的"快慢互补"可能作为涌现性质在工程系统中重现，而非需要被设计对标。
**CLS 的最大价值因此不是"检验三通道的解释力"，而是指出一个具体缺失——parametric 通道的可持续慢速巩固机制——并将该缺失定位为工程前沿而非分类学缺口。** Cartridges 与 MemGen 是对该前沿的最初工程回应；其自发涌现的类认知结构提示：我们可能不需要设计对标 CLS 的系统，而需要给涌现留出通道。

## 10. 框架的适用范围与结语
### 10.1 该框架能做什么
- 为工程选型提供通道级的机制说明：写入形状由什么决定、读取付什么费、失败发生在哪个粒度、换底座时记忆是否存活——部署层决策的物理基础；
- 通过生命周期 × 通道矩阵消解多数归类争议：KV cache 归属、软提示归属、Titans 归属均自然落入矩阵不同单元格，不再需逐案裁决；
- 为成本权衡提供交汇点的物理解释（第 8.1 节三条），使"哪种形态更好"的问题转化为"在哪个生命周期阶段付什么成本"的问题；
- 消解 LMLM 类系统的双状态表观矛盾：检索技能在参数中（parametric，存量子类），知识内容在外部库中（token）——两个状态不是同一状态的两套归类，而是通道矩阵的两个不同单元格。
### 10.2 该框架不能做什么
- 不能裁决"检索是否构成学习"——第 7 节已将其升级为正面小节并给出定义依赖的分解，但框架本身不提供答案；
- 不能预测哪种形态更好——跨形态通用度量衡仍缺失。近期基准开始尝试统一评测：LOCOMO 与 LongMemEval 评估长期对话记忆（Mem0 报告在 LoCoMo 92.5 / LongMemEval 94.4，token 成本比全上下文低 3-4 倍）；MemoryAgentBench（ICLR 2026）以增量多轮交互评估四项能力；MemBench 从有效性、效率、容量三方面评估；LifeAgentBench 覆盖跨维度长程推理。但覆盖仍有限，且多数基准偏 token 通道，parametric 与 latent 的跨形态比较仍无公认协议；
- 不能预判底层架构改变后的通道集合——若非 Transformer 架构成熟，E 维度的收敛结果重开。
### 10.3 已知盲区
1. **循环风险的残留**：先按通道分学科，再用学科分离佐证通道是根本轴。学科分离可能是历史偶然（研究社区的路径依赖），不直接支撑"分离在本体上是必然的"。MemoryAgentBench 等跨形态基准是可能的缓解方向，但当前覆盖不足以完全消解该风险；
2. **分布证据的单源性问题**：社区维护的分类仓库作为数量分布唯一来源，对判据选择敏感、多形态系统计一次还是多次无约定、不可复算。本文将其降格为方向性参考并删除精确百分比。若需分布证据，应通过系统综述协议（预注册判据、多标注者、冲突裁决记录）重新采集；
3. **参数化的子类边界**：存量/增量的分拆解决了部分异质性，但增量内部（微调 vs 适配器 vs 编辑产物）在可回滚性、生效粒度上仍有差异，本框架未进一步细分。
### 10.4 结语
通道框架——token、parametric、latent——是对 agent memory 载体的有用切分，其物理基础（前向计算的信息进入位置）在 Transformer 架构下成立，且已被两份独立综述系统提出。本文的贡献在于：以信息通道五元组重构分析起点，使"三个位置"从第一性约束降格为当前架构下的收敛结果；以生命周期 × 通道矩阵拆解"形态"概念，使多数归类争议自然消解；显式登记边界案例与无共识点；将"检索是否构成学习"从盲区升级为定义依赖的正面分解；将 CLS 类比从参照系收缩为启发源，并定位"parametric 巩固通道缺失"为工程前沿——Cartridges 与 MemGen 是对该前沿的最初回应，其自发涌现的类认知结构提示涌现可能优先于设计。
该框架不是终点，也不是地基——它是**当前工程实践下最有区分力的载体级切分**。它的边界（循环风险残留、分布证据单源、参数化子类边界）是已知且诚实登记的。后续任何在此基础上的工作——无论是单通道深化还是混合系统设计——都应当显式声明自己在哪里越过了这根轴的边界，以及为什么那样做是合理的。

## C. 未解决的遗留缺口（诚实登记）
1. **分布证据未实际重采**——本文声明了单源问题并降格处理，但未执行系统综述协议重新采集。这是资源限制而非原则豁免；
2. **循环风险仅部分缓解**——跨形态基准（MemoryAgentBench 等）的覆盖仍偏 token 通道，不足以完全消解"学科分离可能是历史偶然"的质疑；
3. **parametric 增量子类的内部边界**——微调/适配器/编辑产物在可回滚性与生效粒度上的差异未进一步细分；
4. **"是否存在不依赖新注意力模式的新技能"**——Petrov-Bibi 上限的外推边界（第 4.4 节）登记为开放问题，本文未给出答案；
5. **非 Transformer 架构下的通道集合**——通道框架声称跨架构有效，但该声称本身未经非 Transformer 架构的检验；
6. **Cartridges 的 on/off-context 权衡**——Cartridges++ 发现的权衡意味着固化不是无损的，其长期影响未在本文充分分析。
## D. 编辑立场声明
本修订坚持三个原则：**第一，不宣称本文发现了新分类**——通道框架是对 Hu 等（2025）Forms 轴的重构性安放，不是替代；**第二，所有强度主张配外推边界**——Petrov-Bibi 上限、Xu 泛化天花板、AlphaEdit 提升幅度均配显式边界声明；**第三，所有未解决问题登记为开放**——不将开放问题包装为已解决。v1 中被判定为"文学化"的表述已全部替换为可证伪陈述。若后续工作发现本文任何登记为"事实"的量化数据有误（特别是 KV 存储量级、Cartridges/MemGen 的性能数字），应按错误处理而非解释性重构。
**未做破坏性重构的部分及理由**：三通道的物理基础、各通道的机制刻画、成本结构分析、失败模式分析——这些部分在 v1 中已达到机制层严谨，v3 保留其内容，仅在其上叠加通道框架与生命周期矩阵。破坏性重构应用于分析起点与概念结构，而非推翻已验证的机制描述。
