## Vaswani 等：Transformer 的表征与 attention 计算

**来源与版本。** Ashish Vaswani 等，*Attention Is All You Need*，2017，arXiv:1706.03762 **v7**。[固定版本全文](https://arxiv.org/html/1706.03762v7) · [同版本 PDF](https://arxiv.org/pdf/1706.03762v7)。

**定位与核验。** §3.1 的编码器与解码器结构；§3.2.1、式 (1) 的 scaled dot-product attention；§3.2.2 的多头投影；§3.2.3 的 attention 使用方式与解码器因果遮罩；§3.4 的符号嵌入。定向核对 query/key/value 的计算角色、缩放维度、解码器不能读取未来位置的机制，以及输入符号经 embedding 进入模型的过程。

**支持的具体命题。** 正文中的 attention 公式直接对应这项基础机制。Query/key 的相似性分数经归一化形成读取权重，values 被加权汇总；不同 head 使用不同投影。因果遮罩规定旧位置不能读取后来位置，为固定前缀状态独立于后续问题提供计算前提。

**推导与来源的分界。** 在模型、前缀、位置和相关计算条件一致时，改变后续问题不改变前缀应当产生的状态，这是本文据因果结构给出的解释。原论文不因此被记作跨请求持久化、缓存失效管理或实际服务收益的验证。也不将原始架构的全部细节推广为所有现代模型的实现。

## Hu 等：LoRA 的权重增量

**来源与版本。** Edward J. Hu 等，*LoRA: Low-Rank Adaptation of Large Language Models*，arXiv:2106.09685 **v2**。[固定版本全文](https://arxiv.org/html/2106.09685v2) · [同版本 PDF](https://arxiv.org/pdf/2106.09685v2)。

**定位与核验。** §2、式 (1) 给出完整微调的条件对数似然目标，式 (2) 给出用较少可训练参数表示更新的目标；§4.1、式 (3)：`h = W₀x + ΔWx = W₀x + BAx`，以及同节 *No Additional Inference Latency*；§4.2 的实现与限制。已定向核对训练目标、冻结 `W₀`、训练低秩矩阵以及合并增量的计算角色。正文的整序列负对数似然，是对原文逐输出 token 目标的等价简写；§3 讨论既有方案限制，不作为这项训练目标的定位。

**支持的具体命题。** LoRA 增量作为选定层的权重修正参与映射；冻结主体权重不等于没有可训练的参数增量。本文据此将该实例判为 parametric。增量单独保存到文件，不改变这个接口角色。

**不可推出。** 论文允许将增量合入权重，因此合并后的推理路径可避免额外适配计算；这不证明任意未合并实现、热切换和多租户加载都无额外成本。本文未复现任务分数，也不据此宣称低秩更新无遗忘、可无损撤销或能保存任意新知识。

## Li、Liang：Prefix-Tuning 的连续前缀

**来源与版本。** Xiang Lisa Li、Percy Liang，*Prefix-Tuning: Optimizing Continuous Prompts for Generation*，**ACL-IJCNLP 2021 正式版本**，pp. 4582–4597。[正式记录](https://aclanthology.org/2021.acl-long.353/) · [正式 PDF](https://aclanthology.org/2021.acl-long.353.pdf)。

**定位与核验。** §3.1、式 (1) 对 GPT-2 的逐位置、逐层 activation 及左侧历史依赖作出说明；§4.2、式 (3)；§4.3 的重参数化训练。已核对 prefix 位置的激活由可训练前缀指定，其余位置按冻结模型递推；训练中的 MLP 可在训练后丢弃，保留产出的前缀。主体固定而连续状态可训练，支持正文对“通过主体计算误差、只更新状态”的解释。

**支持的具体命题。** 训练可以构造由冻结模型读取的连续激活状态。本文按前缀的消费接口将这种实例判为 external latent；这是本文与论文“trainable parameters”用词之间明确登记的差别。

**不可推出。** 连续前缀不自动等同离散文本 prompt。优化了前缀不等于修改主体模型权重，也不保证任意事实可写入、任意任务可泛化或所有前缀实现都免去 prefill。本文未复现其生成实验。

## Lewis 等：RAG 的检索、索引与文本消费

**来源与版本。** Patrick Lewis 等，*Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*，arXiv:2005.11401 **v4**。[固定版本全文](https://arxiv.org/html/2005.11401v4) · [同版本 PDF](https://arxiv.org/pdf/2005.11401v4)。

**定位与核验。** §2.1 的 RAG-Sequence / RAG-Token；§2.2 的检索分布：`pη(z|x) ∝ exp(d(z)ᵀq(x))`（PDF p. 3，原式无编号）；§2.3 将输入与检索文本拼接给生成器；§2.4 的训练对象。已核对检索表征与被生成器消费的文档内容之间的分工，并对照 PDF 页图确认公式无编号。

**支持的具体命题。** 文档向量参与选择文档，选中文本通过符号输入供 BART 消费。本文将后一实例路径判为 token；向量索引不因此成为生成器直接读取的 latent 内容。论文的 RAG-Token 名称指逐 token 的文档边际化方式，不是本文 form 名称的定义。

**不可推出。** 该实例不证明检索完全正确、文档可无代价无限增长，或整个系统均不更新参数。向量本身也是神经检索器的输入，但这属于另一个消费者角色。本文未重跑其知识任务或索引更新实验。

## Dai 等：Transformer-XL 的跨片段状态复用

**来源与版本。** Zihang Dai 等，*Transformer-XL: Attentive Language Models Beyond a Fixed-Length Context*，arXiv:1901.02860 **v3**。[固定版本全文](https://arxiv.org/html/1901.02860v3) · [同版本 PDF](https://arxiv.org/pdf/1901.02860v3)。

**定位与核验。** §3.2，递推公式 `h̃ = [SG(h_previous) ∘ h_current]` 及其后的 key/value 构造（PDF 第 3 页，原公式组无编号）；§3.3 的相对位置编码。已核对保存上一片段隐状态、停止其跨片段反向传播并在下一片段重用的机制，并对照 PDF 页图确认公式组无编号。

**支持的具体命题。** 历史激活可以跨声明的计算片段保留，并重新参与后续注意力。这为“持久状态不必只是文本或主体权重”提供机制实例，也说明位置处理是兼容性问题的一部分。

**不可推出。** 论文的跨 segment 不自动等于本文默认的跨 LLM 请求；要纳入后者，仍需登记实际保存期限与可达使用路径。复用 hidden states 不等于任何现代 KV cache 都可直接替换，训练中的 stop-gradient 也不表示主体永不训练。本文未复现速度或困惑度结果。

## Meng 等：ROME 的参数写入过程

**来源与版本。** Kevin Meng 等，*Locating and Editing Factual Associations in GPT*，arXiv:2202.05262 **v5**。[固定版本全文](https://arxiv.org/html/2202.05262v5) · [同版本 PDF](https://arxiv.org/pdf/2202.05262v5)。

**定位与核验。** §3.1，式 (2) 的闭式更新 `Ŵ = W + Λ(C⁻¹k*)ᵀ`、Step 2 对目标 value 的优化；附录 A 的约束更新推导。已核对目标 MLP 映射、目标 key/value、权重秩一更新，以及目标 value 求取中的优化过程。

**支持的具体命题。** 最终写入目标权重可以采用闭式形式；写入算法与被写状态的读取角色是两个问题。本文将该结果判为 parametric，并以它反驳“目标参数只能通过直接对该参数做梯度下降来写入”的全称。

**不可推出。** 目标 value 的求取仍含优化，所以不能称 ROME 全流程没有梯度。定位出的因果敏感位置不自动等于唯一知识存储地址；个别编辑成功不证明全模型可精确解释、无旁效应或任意编辑可组合。本文未复现编辑实验。

## Fang 等：AlphaEdit 的零空间保护条件

**来源与版本。** Junfeng Fang 等，*AlphaEdit: Null-Space Constrained Knowledge Editing for Language Models*，arXiv:2410.02355 **v1**。[固定版本全文](https://arxiv.org/html/2410.02355v1) · [同版本 PDF](https://arxiv.org/pdf/2410.02355v1)。

**定位与核验。** §2.2；§3.1–3.3。式 (7) 是 `ΔK₀ = 0` 下 `(W + Δ)K₀ = WK₀`；加入投影后的 `(W + ΔP)K₀ = WK₀` 对应式 (10)。§3.2 说明以 SVD 构造投影，脚注 2 以 `10⁻²` 阈值处理近零谱值。已核对其保持对象与数值近似条件。

**支持的具体命题。** 在精确零空间条件下，可保持给定 key 矩阵 `K₀` 上的该线性映射，同时构造参数更新。本文将更新后的目标权重判为 parametric；该机制说明保护条件能够具体化。

**不可推出。** 保持这个映射不等于保持所有输入、全部知识或最终输出；有限采样的 `K₀` 和近零阈值也不等于精确全空间保护。连续编辑性能属于论文报告，本文未复现或审定后续实现差异。

## Petrov、Torr、Bibi：前缀注意力的限制

**来源与版本。** Aleksandar Petrov、Philip H. S. Torr、Adel Bibi，*When Do Prompting and Prefix-Tuning Work? A Theory of Capabilities and Limitations*，arXiv:2310.19698 **v2**。[固定版本全文](https://arxiv.org/html/2310.19698v2) · [同版本 PDF](https://arxiv.org/pdf/2310.19698v2)。

**定位与核验。** §4 的前缀注意力分析与可表达映射；§6 的多层影响。已核对在相关内容表征固定时，加入前缀不能任意改变该层内容 token 之间的相对 attention；前缀也会引入自身贡献，并可能改变后续层表征和注意力。

**支持的具体命题。** 特定接口有可推导的结构限制；限制必须携带层、表征和模型假设。本文据此要求把同层相对权重、整体输入输出映射与系统任务能力分别讨论。

**不可推出。** 不能升级为“上下文不能产生新映射”“整个深层模型的相对注意力永不改变”或全部 token memory 的能力上限。动态检索、工具反馈与多步状态更新并未由这一结论统一排除。本文未逐个重证全部定理或复现实验。

## Petrov、Torr、Bibi：连续前缀的通用逼近构造

**来源与版本。** 同三位作者，*Prompting a Pretrained Transformer Can Be a Universal Approximator*。[ICML 2024 正式记录，PMLR 235:40559–40580](https://proceedings.mlr.press/v235/petrov24a.html)。本次机制核对固定为 arXiv:2402.14753 **v1**：[HTML](https://arxiv.org/html/2402.14753v1) · [PDF](https://arxiv.org/pdf/2402.14753v1)；未声称正式版与 v1 逐字一致。

**定位与核验。** §2.1 的连续前缀与“预训练参数”约定；§2.2 定义 3–4；§3 的单头注意力构造；§4 的序列到序列变换；§5 的讨论与限制。已核对特制固定权重、连续前缀及存在性量词，并核对作者未把构造直接等同任意实际预训练模型。

**支持的具体命题。** 冻结权重与前缀接口本身不足以推出普遍表达不可能；存在合适构造时，改变前缀能改变可逼近的映射。

**不可推出。** 不保证任意现成 LLM、短离散 prompt、有限训练数据都可实现这些构造，也不证明有效可学得、样本效率或任务泛化。连续前缀的存在性结果不能直接记成外部文本 memory 已经验证的能力。本文未逐式重证或复现训练。

## Eyuboglu 等：Cartridges 的可保存 KV

**来源与版本。** Sabri Eyuboglu 等，*Cartridges: Lightweight and General-Purpose Long Context Representations via Self-Study*，arXiv:2506.06266 **v1**。[固定版本全文](https://arxiv.org/html/2506.06266v1) · [同版本 PDF](https://arxiv.org/pdf/2506.06266v1)。

**定位与核验。** §3.1–3.3 的工件定义、参数化与服务路径；§4.2、式 (3) 的 context-distillation 目标；§5.1 的质量/成本比较；§5.3 及附录 A.1 的其他参数化。已核对主实现直接优化 K/V、冻结主体模型，以及范式对参数化形式的开放性。

**支持的具体命题。** 可以通过优化构造可复用 KV 工件；本文将该具体实现判为 external latent，不因训练而改称主体参数记忆。论文同时比较 LoRA 参数化，因此不能给整个 Cartridges 范式固定唯一 form。

**不可推出。** 保存 KV 不等于信息已经写回主体权重。压缩指标要保留论文的完整 KV 基线和任务质量条件，不能跨分母拼成 token/latent 通用容量比。本文未复现压缩率、任务效果或服务成本，也不从单篇结果推断所有 latent 的性能。

## 本文自建的定义与判定约定

下面内容由本文负责。它们不是所引论文共同宣布的标准，也不是论文实验已经验证的普遍规律。

| 本文采用什么 | 为何这样登记 | 适用边界与重开条件 |
|---|---|---|
| 默认讨论跨 LLM 请求保留；同一会话内跨请求也包含在内 | 避免单次前向、片段、会话之间移动“持久”的含义 | 若研究单 token 步或其他时间尺度，应明确改边界；TXL 的 segment 不能默认为 request |
| 当前可用 memory 需要保留历史信息，并存在现有机制及允许路径来读出、恢复并消费 | 区分信息仍在、系统可达和任务成功三个层次 | 能否被使用不等于每次都会命中；只设想未来重写软件读取任意字节不算现有路径 |
| 先固定所选模型实现与接口，再分 parametric / external；external 中分 token / latent | 同一数值数组可以扮演不同计算角色，物理位置或优化算法不能代替接口判定 | “外部”相对于所选模型的参数角色，不等于离开 GPU、进程或磁盘 |
| Parametric 指作为所选映射的权重或增量参与计算；token 指经符号输入消费；latent 指按激活、连续前缀或可恢复中间状态消费 | 给 LoRA、文本、前缀和 KV 提供可重复的判例 | 不能仅凭任意数学重写把输入说成复合函数参数，或把权重说成解释器数据，来取消已固定的实现角色 |
| form 登记到具体状态的一次使用关系，而不直接贴给整套 agent 或方法品牌 | 区分源文本、检索索引、派生 KV、生成工件的模型及工件消费者 | 转换、保存或改消费者时重新登记；普通临时激活不自动成为独立持久记忆实例 |
| 选择、更新、作用域和治理是具体任务要求，不全是 memory 的通用入场条件 | 最小按键存取与多主体、可更新、可撤销系统的承诺不同 | 加入新承诺后，原来可省的能力可能变成合格条件；不能由名称预先推出统一组件清单 |

|---|---|---|
| 共享权重更新对不同输入产生不同影响 | 固定单个线性层的输入 x，权重从 W 变为 W+ΔW | 该层变化为 Δh=ΔWx；这解释局部影响怎样依赖输入，不将它直接当作全模型最终行为公式 |
| 冻结主体仍可优化输入状态 | 模型计算对相应状态可微，训练目标的误差可传播到该状态；只更新所选变量 | 梯度可经过固定模型传回前缀或 KV；谁接受更新与结果以后从何处被读取需要分别说明 |
| 因果前缀的计算可以跨后续问题复用 | 前缀不能读取未来；模型、前缀、位置及相关计算条件相容 | 后续问题变化不改变前缀应产生的状态；复用仍需要实际保留、装载并执行后续计算 |
| 保留、可用、实际使用、收益分开 | 历史区别跨边界存在；有实际消费路径；某次运行消费；任务有可比较结果 | 保留不保证可达，可达不保证实际使用或有益；有备份不取消原实例的资格 |
| Token 的保留与当前输入量可分离 | `Selected = Select(Store, Query)`；`Input = Assemble(Current, Selected)` | 库大小、选择质量和本次输入量可分别变化；库扩展不保证找到或用好更多内容 |
| 冻结消费者也能发生完整系统的信息适应 | 固定程序保存新暗号，后续请求按键读取并返回 | 无需修改消费者规则即可获得并利用新的持久信息；不据此证明任意 LLM 可靠调用、归纳新规则或泛化 |
| KV 复用的收支条件 | 同质量、同负载、模型与位置兼容；公共计算确实相同；资源可同单位计价 | 若共使用 n 次且单次构造成本为 Encode，净收益条件为 `(n−1)Encode > Keep+Load+Rebuild+Manage`；右侧均为该时段新增累计费用，不是已测部署排名 |
| KV 体积与历史读取量 | 每层每位置完整保存等维 K/V；或 T 次 query 分别访问 L 到 L+T−1 个历史位置 | 字节数为 `2×层数×KV头数×头维度×单值字节数×位置数`；历史位置参与量为 `LT+T(T−1)/2`，不等于实测延迟或所有架构的成本 |
| 有限容量上界 | 状态总共 B bit、无其他信息来源、要求精确区分任意独立信息 | 至多 `2^B` 个状态；不推出容量已满、每次写入干扰、错误必然全局，或固定尺寸下所有负载相同 |
| 混合的必要性需要可行性排除 | 声明候选集合、任务质量与预算；计入转换、同步、路由、失效成本 | 要证明每种允许的单 form 都不可行，且至少一种混合可行；“成本互补”本身没有完成这个证明 |
| 撤销需要追踪实例与依赖 | 源状态可以产生摘要、索引、KV、参数更新或其他副本 | 删除一个源工件不等于撤销全部派生影响；具体追踪完整性仍需实测 |

其中外部暗号例子是本文构造的可实现性说明；收支不等式是本文的条件推导；容量关系是有限状态计数。三者均没有运行模型行为实验，也没有提供具体部署性能数据。

## 待实测命题登记

实验设计应沿实际状态路径确定失败环节，不能仅因状态改了、模型答对一次或某组件移除后失败，就跳到更强能力结论。

| 待测问题 | 至少要控制和观察什么 | 结果不得越过的边界 |
|---|---|---|
| 某个 LLM agent 是否持续获得并利用新信息 | 写入正确性、跨请求保持、可达检索、输入组装、消费质量；排除预训练已知答案 | 单次回忆与长期可靠性不同；保存新值与规则归纳不同 |
| 外部状态是否支持迁移或泛化 | 新输入、组合或分布变化；训练/评测分离；摘要、副本、缓存等替代路径 | 移除笔记是组件消融，不是完整系统适应的统一否决测试；移除后仍成功也不自动证明主体内巩固 |
| KV 或连续前缀的复用何时划算 | 模型/位置兼容、命中率、构造、装载、存储、重建、后续注意力、管理及质量 | 不把预填充节省当全部生成成本归零；不同质量或硬件不可直接作单数排名 |
| 编辑与更新会否损害已有能力 | 明确保护集、未覆盖输入、连续编辑次序、检索竞争、数值阈值及最终输出 | AlphaEdit 的给定 key 保护、容量上界与实际无干扰表现是不同证据 |
| 撤销、迁移和跨版本使用能否闭环 | 派生链、副本、索引、摘要、KV及参数增量；消费者版本；撤销后的残留行为 | 可读、可编辑或存在管理流程不自动证明可解释、可归因或完整撤销 |

实验应改变相应条件下的可靠性和成本判断；若出现同一判据下无法解释的反例，则直接修改判据。仅增加分类名称或找到另一篇采用不同术语的论文，不足以推翻已经明确的机制判例。
