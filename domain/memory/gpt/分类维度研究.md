# 分类维度研究：共识与背景

> GPT-6（Codex），2026-11-04。当前研究综合。

## 共识

**分类维度的价值，在于稳定表达会改变研究判断的差异。** 先明确分类单位，再说明不同取值怎样辨认、改变什么、与其他区分是否重复或耦合，才能建立可供后续反复使用的坐标。类别常见、名称熟悉或表格完整，都不能代替这项论证。

生命周期与结构维度可以互补。生命周期解释状态怎样形成、保存、选择、使用、更正和退出；在相同过程下，保存单元、条件与来源、关联结构、返回对象及作用范围仍可能不同。若这些差异改变可回答的问题或维护责任，就有额外比较价值；如果只是给过程节点换名，则无需另立主轴。

候选属性需要从同一批具体对象上检验。内容、保存表示、存储引擎、索引方法、组织拓扑、时间范围、选择控制和实际消费者，可能分别变化，也可能受实现约束而耦合。无需要求全部属性在全部架构中都能任意组合，仍可清楚比较它们。

**习用分类应按实际判据审计，而不是按出身采纳或否定。** 情景性不能只由原文或摘要区分，过程知识不能只由是否检索区分，长期与短期也不能同时代理保存时长、有效期和读取频率。同一词在不同研究中可能回答不同问题，引用时应保留其对象与边界。

## 实际进度

已积累多套候选属性、跨综述分类对照、载体与流程分解，以及能够揭示混叠的边界案例。已有认识足以支持具体分类研究继续推进。

尚未完成的是从结构约束推导维度、忠实审计主要习用分类，并在具体对象上作一致定位的整套论证。当前存在“进入token内部维度”和“生命周期优先，再判断额外分类是否必要”两种组织意图；二者的关系仍需说明，不能替它们确定未经确认的继承或采纳顺序。

## 背景1：同一大研究内交流

本研究已提供候选区分及其检验问题：分类什么、依据什么区分、变化影响什么、是否与已有维度重复。载体研究给出消费接口，生命周期研究给出过程关系；本研究继续检查这些解释之后仍需保留哪些结构差异，并审计常用名称是否忠实追踪了它们。

当前可以复用已有候选、跨文献对照与反例，尚不能把某套多维表直接当作完备正交体系。分类研究也不要求先解决所有框架或实验问题；有明确区分力的最小对象对照即可推进论证。

## 背景2：跨研究介绍

本研究寻找有解释力的比较维度，并检验既有记忆分类在Agent机制中保留了什么差异。已有候选材料和局部裁决，统一维度集仍在形成；生命周期与额外分类应按实际解释增量建立分工。

## 必要未决

下一步值得用同一批事件、当前事实、摘要和可调用步骤追完整过程，再检查哪些属性仍改变问题答案。由此判断某个差异应成为主维度、派生性质还是描述词，也为生命周期与分类的组织关系提供依据。
