# 载体研究：已经建立的机制解释、不同稿件的贡献与真正未决点

> GPT-6（Codex），2026-11-03。依据现存原稿重新整理；这是误删后的重建稿，不是被删文件的逐字恢复。原研究、论文核对与本页综合分别承担证据责任。

**本研究最重要的成果，是把“过去怎样影响未来”落实到持续状态及其实际消费方式。** 参数、token、latent 三种路径已经有连贯的机制解释；05、06还把问题扩展到编排、解码和程序执行。后续应保留这些不同尺度的认识，明确使用边界，而不是因为某些总体推论过强就把整批研究降为错误清单，或因新稿较清楚就抹去旧稿贡献。

当前实际状态是：有充分的概念展开、边界案例、一轮机制重构与定向论文核对；尚无这些路线在同一实际任务中的完整效果比较。可以继续进行理论研究，也可以选择需要测量的具体关系；“没有统一实验”不使已经澄清的机制关系失效。

## 1. 现在已经能够解释什么

### 历史影响必须依赖跨边界保留的差异

如果两段不同历史，在当前输入及全部相关可用状态中没有留下区别，在相同过程和随机条件下，系统便没有据此区分两段历史的资源。这是[机制推理稿 §1](../memory-forms%20by%20Codex/推理.md#retention-use-benefit)的基本论证。这里的“全部相关状态”包括研究边界内的存储、参数、运行状态和可再次取得的环境线索；不能只检查一份聊天记录便宣布系统没有记忆。

这项结果把四个问题分开：差异是否仍被保存；当前系统能否找到并消费它；某次运行是否实际使用；使用是否使任务相对基线改善。它们各有独立证据。保留了原文但读取入口不可达，属于可用性问题；检索正确但组装截掉关键条件，属于投递问题；完整条件已经出现而模型仍做错，则还要检查使用与任务能力。把这些情形统称为“记忆失效”会错误地选择改进位置。

复制关系也因此清楚了：增加一个可读取的备份不会使原件和备份同时丧失记忆资格。是否可再生，回答的是恢复路径和成本；是否参与后续历史利用，回答的是记忆关系。二者可以同时成立。旧[06](../mine/02分类/06.md)以“删除后永久丢失”限制资格的判据应局部修正，其余关于来源、副本与操作的讨论仍有价值。

### 三种路径把不同工作放到不同阶段

| 路径 | 长期留下什么，未来怎样使用 | 已能解释的性质 |
|---|---|---|
| 参数记忆 | 保留目标映射的权重变化或参数增量，后续输入通过该映射计算 | 写入改变未来计算；共享计算提供迁移机会，也使修改范围与保护旧行为成为问题。来源追溯通常需另存记录。 |
| Token memory | 保留独立符号记录，未来选取后交给模型重新理解和应用 | 内容与模型可以分别维护；原文、事实、摘要和代码可作为不同表示保存。能定位和编辑，不自动保证读取充分或采用正确。 |
| Latent memory | 保留与消费者适配的连续表征或计算状态，后续经状态接口读取 | 可将部分编码工作提前或复用；兼容条件、状态体积、生成和传输开销成为关键。不同生成、复用、变换机制不能共用一张无条件成本表。 |

这些关系在[现有正文](../memory-forms%20by%20Codex/正文.md)中已从同一条项目约定展开。参数路径不只保存“答得出某事实”，也可以改变识别任务、选择步骤和执行约束的能力；token路径不只存原文，也可以存规则与程序说明；latent路径不只指服务端缓存，也可以指专门生成的持久连续状态。因此，内容叫“事实”还是“技能”，并不单独决定form。

成本也不是一个类别固定承担一项费用。例如token系统可以为自动整理付出很高写入成本；未合并参数模块可能增加加载和推理工作；重复前缀KV可能省去源前缀编码，却仍支付保存、装载和与查询交互的费用。“写贵、读贵、存贵”的提法有助于发现代价位置，但不能代替完整路径比较。已有[推理稿 §6](../memory-forms%20by%20Codex/推理.md#cost-and-reuse)已经把可复用状态的条件收益写得更具体。

## 2. 判到实例和使用关系，才能解决边界案例

当前可复用的判定顺序是：先明确研究的消费者和时间边界；再找到实际持久对象；最后看它在指定实现中作为映射系数、符号输入还是连续数据状态参与计算。[机制推理稿 §2](../memory-forms%20by%20Codex/推理.md#form-contract)对这套口径有完整展开。

LoRA增量作为目标层的系数修正，按该使用关系属于参数路径；连续前缀即便经过训练，若作为冻结主体的状态输入使用，便是另一种路径。训练是生产工件的方法，不等于工件后续必作为主体权重消费。二者机制的原始论文位置已登记在[LoRA条目](../memory-forms%20by%20Codex/index.md#source-lora)与[Prefix-Tuning条目](../memory-forms%20by%20Codex/index.md#source-prefix-tuning)；本页沿用仓内既有核对，不宣称重新复现两篇论文。

检索索引和最终内容也必须分开。向量用于选择一份文本，目标LLM最终读的是文本，不能仅凭系统中出现向量就说它读取了latent记忆。若研究目标改成检索器，其参数与输入又需要另记。来源相同的文本、摘要、索引与KV不是一个可以任意互换的对象。

文本输入产生embedding和KV，首先是一次读取的计算过程。只有相关状态跨选定边界留下并具有后续使用路径，才需要登记额外的持久实例。否则所有token系统都会因产生临时激活被自动叫成混合系统，分类失去区分力。源文本与跨请求KV可以同时存在，分别更新、失效和恢复。

代码则暴露了消费者差异：模型读代码以理解或修改它，与运行器执行代码，是不同事件；程序执行结果再回传给模型，又是一条新的输入路径。解释整个Agent时需要保留两条关系，不能把程序执行全算成LLM的参数记忆，也不能因其没有进入LLM文本输入就说过去经验没有发挥作用。

## 3. forms2、05、06与机制重构，各自推进了什么

[forms2](../mine/02分类/forms2.md)是多块稿件的拼接，包含v1、未编号稿、v2、v3、v4、v5、v7；版本号不足以证明单线继承。其重要贡献是反复碰撞保留边界、读取判据、地址性、成本和能力等问题，积累了软提示、KV、检索与技能等边界案例，并将后续token组织问题显式提出。v5采用请求边界，v7改为单次前向；同一临时KV在两种范围下的地位可能不同。这首先是研究集合变化，需要声明，而非靠“最新版本”消除。

[05](../mine/02分类/05.md)将信息通道写成进入位置、持久边界、时间粒度、作用域、可变性五元组。这个扩展保留了有价值的认识：相同进入位置仍可能对应完全不同的生命周期、租户范围和更新机制；单一form标签不够解释系统。五元组并未证明五项完全独立，但多属性记录本身不因此无效。其关于检索是否构成持续学习、机制获得与能力获得的讨论，也超出了纯名称归类。

[06](../mine/02分类/06.md)将对象扩为包含编排、模型与解码的管线，显式纳入控制态、解码约束和程序。其正向贡献是承认：Agent经验可以改变目标模型之外的路由、任务状态和可执行资产，且这些变化可能直接改变后续行动。这个问题不能在以目标LLM为中心的三形态稿里自动得到全部回答。

但扩大对象与证明旧分类错误是两回事。05把编排代码并入parametric，而又用目标模型系数定义parametric，存在口径切换；06把所有映射通道推广为必然全局竞争，也超过有限容量论证能得到的结果。应保留它们提出的新对象，修正相应全称命题，而不是将其整体当作“被新稿替代”。

[Codex机制重构](../memory-forms%20by%20Codex/正文.md)的具体推进，是在限定目标模型、实际接口和跨请求边界后，给出可连续阅读的三路径解释，并将推导与一手来源账本相连。它已处理多项旧争议：容量上界不含逐次干扰，局部attention限制不能直接成为整个token通道的能力上限，成本互补也不能直接证明混合必要性。它提供较清楚的工作起点，但不能代替05/06全部系统范围研究。

## 4. 现在值得处理的未决问题

第一，**模型记忆与系统持久资产之间怎样连接**。可以把三路径作为目标模型接口的解释，再用消费者关系登记控制态与程序，而不是不断扩展一张互斥分类表。值得检验的是：同一具体资产在两种解释范围中是否遗漏或重复，新增属性是否解释了真实差异。

第二，**哪些性质由接口决定，哪些由具体实现与任务决定**。参数作为系数、文本作为符号、状态作为连续输入，是明确的机制差异；实际费用、可迁移性、错误定位能力和撤销完整性，还取决于资源、数据、默认路径与辅助状态。后续比较应保留这一分工，避免从form名称直接推出优劣。

第三，**载体、生命周期和token内部维度的接口**。载体提供物理与计算条件，生命周期描述状态怎样随事件改变，结构维度比较不同系统可以选择什么。它们可以分别深入，也要在作用点上相遇。当前已经有足够机制材料支持后两项继续研究；是否先讲生命周期，仓内还保留另一种明确研究意图，见[分类维度研究](分类维度研究.md)。

供其他研究使用的短介绍：本课题已解释历史如何以权重变化、符号记录、连续状态及系统资产参与后续行动，并积累了具体边界判例。可以继承实例、消费者、保留边界和条件成本等分析方法；不能继承无条件的容量、干扰、混合必要性或性能排名。旧稿的不同尺度应按问题使用，当前不需要再次写一份全景稿才能开展后续研究。
