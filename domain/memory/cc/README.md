# Agent Memory 第一性原理研究

## 研究定位

本研究基于第一性原理（First Principles）深入分析 Agent Memory 的本质、核心计算模型和关键操作。

### 核心问题

Memory 系统的本质不是"如何分类记忆"，而是**在有限预算下，决定什么信息、以什么形态、在什么时候进入上下文**。

### 研究主线

1. **第一性约束推导** - 从 LLM 的三个不可回避约束推导 Memory 的必然性
2. **核心计算模型** - Token-level Memory 的五问题模型（Q1-Q5）
3. **关键操作研究** - Forget 和 Consolidate 的深度分析
4. **经验谱系理论** - Experiential-Skill 的编译-解释连续谱

### 方法论原则

- **多轴投影意识** - 不同分类是同一对象在不同维度的投影
- **课题分离** - 理解框架 ≠ 研究框架
- **理论最小性 vs 工程可用性** - 理论层追求正交，工程层允许冗余
- **连续谱意识** - 不把动态过程人为离散化
- **反速记意识** - 经典分类是属性组合的速记，不是本质
