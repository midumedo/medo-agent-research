# 介绍
本研究 `docsclassify` 是 `repo-context` 的一个子研究，研究文档分类模型并做初步分类。

# 行动方针
不必过于追求与同级子研究的解耦，这是中间态的东西，允许研究重叠，去重留给之后的总体性整理（本研究不考虑）。
具有参考意义的文件，应该保留下来。

# index
下面有 `v1`、`v2`、`v3` 三个子文件夹，代表三个大版本。
每个子文件夹的 `draft{n}` 文件是 `v{n}\` 的**核心文件**：都是我纯手写的，我有着最完整的认知。
其它 `{ai}.md` 是 `{ai}` 基于 `draft{n}` 的讨论。
下一份 draft 来自上一份讨论的大概想法，都是我亲自确认过的。
不同文件夹中的相同 `{ai}` 并无绝对继承关系。

# context
文档模型：对文档类型进行建模，并非 AI model。
