# V11：从文档承担的工作重新研究类型

> 状态：研究进行中。这里的分类是要由正文和使用任务支持、也可以被反例推翻的解释，不是对仓库的规范要求。

V11 重新检查 Agent 开发相关文档及其依赖的通用文档。研究对象是文档保存或规定的信息、它支持的判断/行动、与其他内容的关系，以及这些内容何时变化。目标是解释哪些差异会影响正确理解或行动，哪些只是名称、载体和位置变化。

本轮重开源于前一版 02 将模型、样本映射和文档定义混在一起。现将职责恢复为：

- `00docslist` 保存固定样本的观察入口和原始账目；它不是定义，也不保证完整代表 AI 时代文档。
- `01docsclassify` 从样本文本和实际任务推导模型，记录支持它的边界案例、反例和证据限制；通用项目文档是并列研究对象。
- 后续定义阶段在本研究结果上写可引用的语义文档定义；本研究不引用或依赖该阶段的文件。

## 阅读顺序

- [研究方法与证据](研究方法与证据.md)：从使用问题推导差异，区分观察、来源自述、消费者行为与效果证据。
- [文档职责研究](文档职责研究.md)：当前可由样本支持的差异、组合关系和仍待判断的边界。
- [样本判例](样本判例.md)：用实际正文检验同名异职、异名同职、混合职责和演化差异。
- [输入线索说明](输入线索/状态说明.md)：从旧阶段移来的候选模型、映射和缺口；只供查找，不继承其结论。原始文件见同目录。

## 样本边界

本轮从 [00 的索引](../../00docslist/index.csv) 与逐仓明细出发。它登记的是 2026-09-25 取证范围内的仓库根级文档和部分 Agent 面，不是“所有 AI 文档”的全集。00 的 `kind`、`role`、文件名、行数和 `verified` 状态都不直接决定模型或定义。

核读来源包括固定 checkout 中的原文。文档正文能证明该来源写了什么、如何自我定位；只有追到解析、发现、读取和投递路径，才能说明消费者实际上怎样处理它；只有针对任务的实验才能支持行为效果。未取得后一层证据时，不把意图写成运行事实。

样本用途与覆盖方式不由旧 `role` 或表格完备性决定。研究必须保留足以追溯判断的实例路径和原文证据；某一类型的成立条件、边界或变化规律尚无足够正文证据时，保留为开放问题，由 02 暂不写成已核定定义。
