# 02：文档定义

## 当前定义稿

[文档定义 v1](文档定义v1.md) 是当前候选定义稿。它以 `docslist.md` 的原始名称为候选材料，从信息任务、成立所需关系和更新/权威差异出发做初步去重；为主要文档给出简明定义和常见结构大标题，并逐项保留原始名称的映射关系。

[主要 Vibe 文档定义：具体名称稿](主要Vibe文档定义-可读稿.md) 直接以 `AGENTS.md`、`ARCHITECTURE.md`、`CONTEXT.md` 等具体候选名为条目，分别提出定义、边界和大标题设想。它用于审阅定义是否足够具体，不取代 v1 的全量候选映射，也不表示这些定义已经定型。

这是一版可修订的研究定义，不是行业分类或强制规范。它不声称候选名称都对应真实、常见或有效的文件，不回读样本仓库原文，也不以旧模型、旧编号或旧样本定义作为结论依据。
