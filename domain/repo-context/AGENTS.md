# 思维模式

# 背景

大部分项目里的实际使用，并没有做到vibe coding的最佳实践。
大量的冗余，认知税。
所以实际项目的用法，只能作为参考。
必须基于第一性原理，从agent 和 harness 的 角度，深度思考每个文档。

# 最终目的
1. 整理好原理，减少重复和无用的试错与方向
2. 定义好每个vibe doc
3. 讨论清楚管理vibe docs 的 skill 的 第一性原理。把原理捋清楚了，可以让模型发挥智能进行设计。
4. 进而设计管理vibe docs 的 skill。但是核心是落在原理上，具体实践由ai的智能结合项目本身进行设计。
需要基于第一性原理，深度思考。要摆脱既有偏见。
