# 转换疑点核对

遇到拆词、漏字、错误上下标或段落异常时使用。先读完整语境，再用 `pdf_read.py --find` 找页、`--pages` 读对应文本；字体、公式、上下标或版面仍有歧义时用 `--render` 看页面。

## 容易误判的几类内容

- `Lar<sub>g</sub>e` 可能只是错误标签；`Mem0<sup>g</sup>` 可能是真实方法名；`x<sub>i</sub>` 可能是公式。标签形状和数量不能决定是否改动。
- 删标签不一定修好字符。例如 `LLM<sub>s e</sub>f<sub>ec</sub>ti<sub>ve</sub>l<sub>y</sub>` 去标签仍得到 `LLMs efectively`；是否补第二个 `f` 应由 PDF 证明。
- PDF 文本层可能损失上标、连字和阅读顺序。它是定位与字符线索，不能替代页面核对。
- 表格、代码和提示词里的标签可能就是作者内容，不能当作普通正文批量清理。

确认后直接编辑 MD，保持来源含义、表格公式和图片关系。重复且含义一致的问题可以批量替换，再看实际 diff 与对应 PDF。没有版本记录且需大幅修改时，先在临时目录留原文副本。

找不到对应来源或仍有多种解释时，留下疑点与定位信息。需要长期保留的是来源位置、修改依据和误判反例；临时页图与一次性查询脚本不必成为论文库的一部分。
