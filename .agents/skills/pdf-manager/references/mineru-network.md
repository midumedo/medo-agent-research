# MinerU 连接诊断与批次续取

出现上传、查询或结果下载错误时使用。先确定失败阶段；HTTP 状态、TLS 异常或正在使用 VPN，都不能单独确定故障原因。

## 按失败阶段处理

| 失败位置 | 可判断的事实与下一步 |
|---|---|
| 申请批次的 API 请求失败 | 尚无可续取批次时，核对凭据、参数、服务返回与 API 连接；CDN 回退不覆盖这里。 |
| 已取得 `batch_id`，但 PDF 上传失败 | 批次存在不表示文件已上传或解析。当前 CLI 不会用 `--batch-id` 补传 PDF；先查该文件状态，确认上传未完成后只重提失败文件。 |
| 查询中断或等待超时 | 保留批次和原输入，使用下方命令继续查询；不要因未拿到状态而重传全部文件。 |
| 云端已 `done`，结果 ZIP 下载失败 | 解析已完成，优先续取原批次；连接异常可能触发下述局部回退。 |
| 云端返回 `failed` | 读取 `err_msg`，修正实际原因后再决定是否提交新任务；换 DNS 地址不会修复解析失败。 |
| ZIP 无效或本地写入失败 | 依错误检查响应内容、空间或名称冲突；不把它归为 VPN 故障。 |

```text
python "<脚本>" convert "a/pdf/原文件名.pdf" --batch-id "<已有批次>" --timeout 120
```

`<脚本>` 为 skill 内 `scripts/pdf_manager.py`。保持原 PDF 与文件名，续取需要按返回的 `file_name` 匹配。它只重新查询当前结果地址并整包下载，不申请新批次、不上传文件，也不是字节级断点续传。完整产物默认跳过；下载失败项通常不需要 `--force`。

`--timeout` 只控制批次轮询等待。API 单次请求、上传和下载分别有连接或读写超时，因此命令耗时可能超过这个值；不能把它当作整个命令的硬截止时间。

## 自动回退的精确范围

实现位于 [mineru_backend.py](../scripts/mineru_backend.py) 的 `_download_zip`、`_cdn_fallback`、`_HTTPSAtAddress`；以下是当前脚本行为，不是 MinerU 的服务保证。

1. 结果下载先使用正常 `urllib` 路径。只有连接、TLS 或传输异常，且原 URL 是 `https://cdn-mineru.openxlab.org.cn`、端口省略或为 443，才尝试地址回退；其他站点、上传和 API 请求不应用这套回退。
2. 依次通过 AliDNS、Cloudflare 的 HTTPS DNS 服务查询 A 记录。DNS 查询参数只有域名与记录类型，不携带结果 URL 的签名、路径或 MinerU Token。每个解析器最多取两个公网 IPv4，跨解析器去重，总共最多尝试四个不同地址，不保存或硬编码 CDN IP。
3. 连接实时地址，仍用原 CDN 域名发送 TLS SNI 与 HTTP Host，并校验证书和主机名。正常下载和 DNS 查询使用当前 `urllib` 代理路径；地址连接不使用该应用代理，但仍可能经过操作系统路由和 VPN/TUN。脚本不修改系统代理、VPN、hosts 或证书设置。
4. 普通路径的 HTTP 错误（包括 403、429、5xx）直接报告，不触发地址回退；地址回退只接受 200，遇重定向或其他状态也停止。取得响应后检查是否为 ZIP，无效 ZIP 不继续换地址。

这些重试有次数上限，不能据此承诺整体耗时或成功率。当前超时参数为：正常下载 600 秒、每次 HTTPS DNS 查询 12 秒、地址连接与 TLS 阶段 30 秒、随后 socket 操作 600 秒；它们都不是命令的总时限。

回退失败时保留失败阶段、错误类型或 HTTP 状态以及批次编号。先核对这一阶段的网络访问、代理规则与服务状态；不要反复提交解析，也不要把关闭证书校验或固定 CDN IP 作为处理方式。日志不记录 Token、签名链接或文档正文。

## VPN 问题可以怎样准确表述

2026-11-02 的本机观测：有本地代理与隧道适配器，系统 DNS 对相关域名返回 `198.18.0.x`；正常域名下载出现 TLS EOF。保持 VPN 开启、使用实时公共 DNS 地址并保留原域名证书校验后，多个地址下载成功，原批次产物取回，随后三次重复下载成功。

这把排查范围收敛到**当时的域名解析或访问路径差异**，没有隔离出具体 VPN 规则、DNS 组件或单一根因。稳定说法是：“该环境下的常规 CDN 访问路径曾失败，局部地址回退已恢复过下载；无需重新解析。”不能扩展为“VPN 一定导致故障”“已绕过 VPN”或“今后必定稳定”。

这些是日期明确的历史实测。离线测试可验证回退条件、次数、域名与证书处理；它们不证明当前网络可达或长期可用性。排查时保留这一区分。

实现参考：[Python 默认 TLS 上下文与主机名校验](https://docs.python.org/3/library/ssl.html#ssl.create_default_context)、[Cloudflare HTTPS DNS JSON 格式](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)。
